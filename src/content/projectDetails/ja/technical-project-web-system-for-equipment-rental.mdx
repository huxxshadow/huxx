## 担当業務

この2ヶ月間の個人フルスタック開発プロジェクトにおいて、要件分析・システム設計からフロントエンド/バックエンド実装・デプロイテストまでの完全な開発フローを独立して完成させました。主な業務内容は以下のとおりです。

* **システムアーキテクチャ設計とフルスタック開発**：機器貸出管理システムのフロントエンド/バックエンドアーキテクチャ全体の構築を担当。フロントエンドは Vue 3・Vue Router・Bootstrap 5 でレスポンシブインターフェースを構築し、バックエンドは Node.js・Express.js・MongoDB で RESTful API とデータ永続化を実装しました。
* **アクセス制御と認証メカニズムの実装**：**JWT** ベースの身元認証とロールベースアクセス制御メカニズムを設計・実装し、管理者と一般ユーザーの操作境界を区別することで、機器管理・ユーザー管理・貸出フローのセキュリティを確保しました。
* **機器・ユーザー管理モジュールの開発**：機器情報管理・ユーザー情報管理・機器検索・ステータス追跡・貸出記録管理などのコアビジネス機能を実装し、管理者によるシステムリソースの一元管理をサポートしました。
* **貸出フローとカレンダー可視化の設計**：機器の借用・返却の完全なビジネスフローを開発し、機器の貸出状況と時間的競合を表示するカレンダービューを統合することで、機器スケジューリングの可視化と管理性を向上させました。
* **フロントエンド/バックエンド連携とインタラクション最適化**：API 連携・フォームバリデーション・エラー状態処理・インタラクション体験の最適化を担当し、さまざまなデバイスでのシステムの使いやすさと操作のスムーズさを確保しました。
