## 担当業務

4人で構成されたデータベース管理システムのチームプロジェクトにおいて、チームリーダー・アプリケーション開発者・データベース設計者を担当しました。主な業務内容は以下のとおりです。

* **データベースアーキテクチャ設計**：システムの概念設計と論理設計を主導し、コアビジネスプロセスの実体関連図（ERD）をゼロから作成して、データ冗長性を効果的に削減する正規化されたリレーショナルデータベーステーブルへと厳密に変換しました。
* **バックエンドロジックとデータ整合性の維持**：コア SQL スクリプトを記述してテーブル構造を構築し、フライト予約・キャンセルなどの複雑なビジネスシナリオにおけるデータ整合性と一貫性を確保するための PL/SQL トリガー（Triggers）を開発しました。
* **アプリケーション層の開発と統合**：Java と JDBC API を用いてアプリケーション層と Oracle データベース間の低レベルインタラクションを実装し、フライト検索・座席予約・動的割引運賃計算などのコア機能を正常に連結しました。

## プロジェクト詳細

本プロジェクトは、香港浸会大学コンピュータサイエンス学科のデータベース管理システムコースの最終実践プロジェクトであり、エンドツーエンドのフライト予約システムを設計・実装することを目的としています。技術的には、システムバックエンドを Oracle データベースで構築し、アプリケーション層を Java で開発して JDBC を用いた双方向データインタラクションを実現しました。開発ライフサイクル全体を通じて、チームはデータベース設計の標準パラダイムに厳密に従いました。まずフライト・顧客・注文などのコアエンティティを明確にして ERD モデリングを完成させ、次に主キー・外部キーの定義とデータベース正規化処理を実施し、最後に基盤アーキテクチャと上位ビジネスロジックを深く結合させました。チケットシステムの厳密性を確保するために、データベース内に PL/SQL トリガーを配置してフライトの残席数をリアルタイムで同期させ、乗り継ぎ回数に基づいて段階的割引を自動計算するようにしました。本プロジェクトは、要件分析・データベース論理設計から最終的なアプリケーション統合までの完全なパイプラインを網羅しており、データベース理論とエンジニアリング実践の総合的な検証となっています。
