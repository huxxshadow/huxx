## 担当業務

この Java ベースの Discord チャットボットプロジェクトにおいて、コア機能モジュールの開発とオブジェクト指向設計の実装を主に担当しました。主な業務内容は以下のとおりです。

* **コア機能の開発**：認証ボットと成績照会ボットを独立して設計・実装し、ユーザーの特定コマンドとテキストメッセージへの正確な応答を実現しました。
* **アーキテクチャ設計と実装**：ポリモーフィズム・抽象クラス・インターフェースなどのオブジェクト指向プログラミングのコアコンセプトを深く活用し、抽象基底クラスに基づくモジュラーシステムアーキテクチャの構築に参加しました。
* **コマンドとメッセージの処理**：統合と分離の処理ロジックを担当し、スラッシュコマンドの解析を CommandBot に委ねる一方、日常会話と簡単なインタラクションを TextBot が監視・応答するよう設計しました。

## プロジェクト詳細

本プロジェクトはオブジェクト指向プログラミングコースの最終実践プロジェクトであり、機能豊富な Discord チャットボットの開発を通じてポリモーフィズム・インターフェース継承・複雑なシステムアーキテクチャ設計などのコアプログラミング思想を総合的に応用・定着させることを目的としています。

技術実装においては、Java と低レベル通信ライブラリ（Java Discord API）をベースに、高度なモジュラーアーキテクチャ設計を採用しました。システム内のすべての具体的な機能モジュール（ネットワーク遅延のテスト・試験座席番号の照会・ユーザー登録の管理・身元確認・成績確認を担うボットなど）は、同一の統一された抽象基底クラスを継承しています。異なるタイプのユーザーインタラクションを正確に処理するため、インタラクションメカニズムをスラッシュコマンドを解析する CommandBot と通常のテキストメッセージを監視する TextBot の2種類に分類しました。この抽象化とポリモーフィズムの設計は、コードの再利用性と保守性を大幅に向上させるとともに、将来的なさらなる実用的機能の拡張に向けた堅固なアーキテクチャ基盤を築きました。
