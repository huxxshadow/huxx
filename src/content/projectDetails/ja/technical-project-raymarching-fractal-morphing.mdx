## V2 · フラクタル表面融合DCCツール

フラクタル表面融合 DCC ツールは、任意の 3D モデルをフラクタル幾何と融合し、細部がどこまでも展開していくフラクタル表面をブラウザ上でリアルタイムにレンダリングします。さらに GPU によるジオメトリ処理で、そのまま制作に使える高精度な水密メッシュを書き出せます。このバージョンではフラクタル場、融合方式、マテリアルシステム、メッシュ書き出しを Three.js でゼロから構築し、従来の DCC ソフトで時間のかかっていたフラクタルのモデリングとベイクを「ブラウザでリアルタイムに調整し、ワンクリックで書き出す」ワークフローに変えました。

### 担当業務

個人プロジェクトとして、レンダラーからツールチェーンまですべて一人で開発しました。

- **フラクタル場と融合**：Mandelbulb の距離推定とボクセル密度場の 2 種類のフラクタル場を実装し、モデルの符号付き距離場を GPU でベイク。シェルラップ、空間ワープ、SDF ブレンド、ブーリアン、サーフェスカービングなどの融合方式を設計しました。
- **無限ディテールのリアルタイムレンダリング**：フルスクリーンのレイマーチングシェーダー、静止時のプログレッシブスーパーサンプリング、ソフトシャドウ、イメージベースドライティング、スタジオ床面により、どの拡大率でもフラクタルの細部を鮮明に保ちます。
- **ジオメトリ処理と書き出し**：ブロック単位の GPU サンプリングと、ブロック間で頂点を溶接する Marching Cubes により、陰関数で表されたフラクタル表面を高精度な水密メッシュに変換し、GLB / PLY / STL で Blender などの DCC ツールへ直接渡せます。
- **マテリアルとツール化**：フラクタルの反復情報に基づくシェーディングに、サブサーフェススキャタリング、透過、クリアコート、薄膜干渉、自己発光を追加。シーンプリセット、パラメータファイル、中英 UI、4K オフライン録画も用意しました。

### モデルとフラクタルの融合

融合の本質は 2 つの距離場の組み合わせです。読み込んだモデルはまず GPU 上で 3D の符号付き距離場にベイクされ（three-mesh-bvh で最近点を求め、7 本のレイの多数決で内外を判定）、フラクタルは反復式で定義された陰関数場として扱います。

デフォルトの**シェルラップ**モードは、フラクタル空間をモデルの表面に「貼り付け」ます。モデル付近の各点を、中心からの方向または表面法線の方向に沿ってフラクタル球のいずれかの殻に写像することで、フラクタルの模様がモデルの輪郭に沿って成長します。融合度は 0 から 1 まで連続的に変化し、途中の状態では元の形を保ちながらフラクタルの細部が徐々に現れます。このほか、空間ワープ、スムーズな SDF ブレンド、交差 / 差 / 和のブーリアン、サーフェスカービングにも対応しています。

### 無限ディテールのリアルタイムレンダリング

フラクタル表面はメッシュではなく、任意のスケールで評価できる数式です。そのためレンダリングはシェーダー内で直接行います。フルスクリーンの四角形がピクセルごとにレイを飛ばし、距離推定を使って表面へ近づいていきます。Mandelbulb は解析的な距離推定を用いるため、カメラを寄せるほど細部が展開し続けます。ボクセル密度場モードは 3D テクスチャにベイクしたうえでトライキュービック B スプライン補間でサンプリングし、ボクセルのブロック感のない滑らかで連続した表面を保ちます。

カメラが静止している間は、Halton 列でピクセルをサブピクセル単位にジッターしながらフレームを蓄積し、面光源の位置もジッターすることで、アンチエイリアスと柔らかいソフトシャドウを得ます。ドラッグ中は自動的に解像度を下げて操作の滑らかさを保ちます。ライティングはキーライト、リムライト、イメージベースドの環境反射、スタジオ床面で構成しています。

### マテリアルとライティング

マテリアルシステムの土台はフラクタルシェーディングです。フラクタル反復中の軌道情報から Color Map を計算し、アンビエントオクルージョンとバンプを組み合わせて、ベースカラー、メタリックのアクセントカラー、隙間の色を表面の各層に割り当てることで、グレーとゴールドが入り組んだ質感を作ります。

その上に複数の表面レイヤーを追加しました。サブサーフェススキャタリング、屈折方向に沿って内部をマーチングし Beer-Lambert 則で吸収する透過、クリアコート、薄膜干渉による虹彩、隙間や色帯に沿った自己発光です。これらを組み合わせて、翡翠、虹彩の甲殻、溶岩の亀裂、釉薬陶器、ブラックゴールド、クロームとゴールド、緑青などのプリセットを用意しており、すべてのパラメータをリアルタイムに調整できます。

### ジオメトリ処理と高精度書き出し

リアルタイムプレビューと並ぶもう一つの柱が、陰関数のフラクタル表面を実際のジオメトリに変換する処理です。書き出し時には計算領域を 129³ のブロックに分割し、GPU でブロックごとに距離場をサンプリングし、表面を含むブロックだけに Marching Cubes を適用します。ブロック境界では頂点を溶接するので、継ぎ目のない水密メッシュが得られます。グリッドは最大 2048³ まで対応し、目に見えるフラクタルの細部を十分に保持できます。

法線と頂点カラーは同じシェーダーで GPU 上で計算するため、書き出し結果はプレビューと一致します。さらに等値面に沿った表面の厚み付け、元モデルの寸法への復元、GLB をグレーのベースとゴールドのアクセントの 2 マテリアルに分割する機能もあり、Blender に読み込んでそのままレンダリングや 3D プリントに使えます。

### 担当業務

WebGL と Three.js を用いたこのフラクタルモーフィングプロジェクトにおいて、フラクタルレンダリングアルゴリズムの設計、モーフィングロジックの実装、全体的な可視化パイプラインの開発を主に担当しました。主な業務内容は以下のとおりです。

* **レイマーチングレンダリングの実装**：Signed Distance Function（SDF）に基づくレイマーチングレンダリングパイプラインを構築し、プロシージャルジオメトリとフラクタル構造のリアルタイム表面交差・可視化を実現しました。
* **Mandelbulb フラクタルのモデリング**：3D Mandelbulb フラクタルの距離推定関数を実装し、反復公式・球面座標変換・導関数累積によって自己相似的な細部を持つ三次元フラクタル構造を生成しました。
* **モーフィングシステムの開発**：通常の3Dモデルと Mandelbulb フラクタル間のスムーズなモーフィング手法を設計・実装し、数学的レベルで異なる SDF を合成して連続的な中間形状を生成しました。
* **インタラクションとパラメータ制御**：Three.js を用いたインタラクティブな Web 表示環境を構築し、フラクタルの反復回数・変形強度・スムーズさなどのパラメータ調整をサポートして可視化品質と実験的表現を向上させました。


### プロジェクト詳細

本プロジェクトは、従来の3Dモデルと数学的フラクタルの連続的な形状遷移を探求し、Web ベースのインタラクティブレンダリングによってこの幾何学的表現方式の変化プロセスを可視化することを目的としています。技術実装においては、Signed Distance Function に基づくレイマーチング手法をコアレンダリング手段として採用し、プログラム的に定義された複雑なジオメトリへのリアルタイム交差・シェーディングを可能にしました。フラクタル部分は Mandelbulb 構造に基づいて実装されており、3次元球面座標における点の冪乗回転と反復によって豊富な自己相似的細部を持つ三次元フラクタル形状を生成できます。モデルとフラクタルの間のスムーズな遷移を実現するため、プロシージャルモデルの SDF と Mandelbulb の距離場を数学的レベルで合成し、smooth minimum と線形補間を組み合わせた連続的なモーフィングプロセスを構築しました。中間状態は元のモデルの輪郭を保ちながら、徐々にフラクタルの細部を表現します。本プロジェクトは、WebGL・Three.js・プロシージャルジオメトリ技術の複雑な視覚生成とインタラクティブ3Dアート表現への応用可能性を示しています。
