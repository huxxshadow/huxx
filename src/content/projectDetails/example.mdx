## Code and Preformatted Text

For technical projects, you'll often need to share code. Your `project-prose` styles will wrap code blocks in a nice tinted background with a solid border.

```csharp
// FlipperController.cs
public class FlipperController : MonoBehaviour
{
    public float hitStrength = 10000f;
    public float flipperDamper = 150f;
    private HingeJoint2D hinge;

    void Start()
    {
        hinge = GetComponent<HingeJoint2D>();
        hinge.useLimits = true;
    }

    public void ActivateFlipper()
    {
        // Custom angular velocity logic here instead of standard motor
        JointMotor2D motor = hinge.motor;
        motor.motorSpeed = hitStrength;
        hinge.motor = motor;
    }
}
```
