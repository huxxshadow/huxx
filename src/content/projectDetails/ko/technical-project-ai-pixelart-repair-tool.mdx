## 담당 업무

이 1주일간의 개인 툴 개발 프로젝트에서 알고리즘 설계부터 제품 구현까지의 완전한 개발 플로우를 독립적으로 완성했습니다. 주요 업무 내용은 다음과 같습니다.

* **이미지 처리 알고리즘 설계 및 구현**: Python으로 픽셀 아트 스타일 이미지 최적화를 위한 처리 파이프라인을 구축하고, 다양한 픽셀화·색상 양자화·엣지 복구 알고리즘을 통합하여 AI 생성 소재에서 흔히 발생하는 픽셀 아트 스타일 편차 문제를 수정했습니다.
* **GPU 가속 및 성능 최적화**: 고해상도 이미지와 배치 처리 시나리오를 위해 cuML과 cuPy를 도입하여 K-Means 색상 클러스터링과 배열 계산 플로우의 GPU 가속을 적용하여 처리 효율을 크게 향상시켰습니다.
* **인터랙티브 웹 툴 개발**: Gradio로 시각화 인터페이스를 구축하여 사용자가 직접 이미지를 업로드하고 파라미터를 조정하며 결과를 실시간으로 미리보고, 여러 처리 방안을 동시에 생성하여 비교할 수 있도록 했습니다.
* **툴화된 워크플로우 설계**: 게임 아트 소재 제작 요구사항을 중심으로 엣지 복구·픽셀 블록 감지·색상 압축 등의 여러 기능 모듈을 설계하여 단순히 이미지를 수정하는 것에서 나아가 픽셀 소재의 제작 기준을 분석·규격화하는 데 도움이 되도록 했습니다.

## 기술적 하이라이트

* **픽셀화 알고리즘 통합**: 클래식한 최근접 이웃 픽셀화·모자이크·유화·계층 픽셀화 등 다양한 스타일화 처리 방식을 지원합니다.
* **풍부한 색상 양자화 전략**: K-Means·Median Cut·Floyd-Steinberg 디더링·지각 가중치 강화 방식을 지원합니다.
* **GPU 가속 능력**: cuML과 cuPy를 결합하여 CUDA 지원 환경에서 고해상도 이미지 처리 효율을 크게 향상시킵니다.
* **엣지 복구 모듈**: Canny 엣지 검출·형태학적 처리·커스텀 이웃 평균 알고리즘을 기반으로 엣지 손상과 노이즈 문제를 최적화합니다.
* **픽셀 블록 감지 분석**: 이미지 내의 일반적인 픽셀 블록 크기를 추론하여 픽셀 소재 제작 플로우의 규격화를 지원합니다.
* **Gradio 시각화 인터페이스**: 이미지 업로드·파라미터 조정·실시간 미리보기·다중 방안 결과 출력을 지원하여 비개발자도 쉽게 사용할 수 있습니다.

## 프로젝트 상세

**AI PixelArt Repair Tool**은 게임 개발과 픽셀 아트 워크플로우를 위한 이미지 복구 툴로, MidJourney 등의 AI 드로잉 툴이 생성한 "의사 픽셀 아트" 소재를 최적화하는 것을 주된 목적으로 합니다. 이러한 AI 툴은 빠르게 고품질의 비주얼 스케치를 생성할 수 있지만 생성 결과는 픽셀 경계가 불명확하고·색상 수가 제어되지 않으며·로컬 엣지가 손상되어 있고·그리드 구조가 불통일한 문제를 자주 가지고 있어 2D 픽셀 게임 프로젝트에 직접 사용하기가 어렵습니다.

소재의 사용 가능성을 향상시키고 후처리 수작업 수정 비용을 줄이기 위해, "픽셀화 처리"·"색상 양자화"·"엣지 감지 및 복구"·"픽셀 블록 분석" 등의 단계를 통합한 워크플로우를 갖춘 이 툴을 개발했습니다. 사용자는 소재 특성에 따라 서로 다른 알고리즘을 유연하게 조합하여 실제 픽셀 아트 기준에 더 가까운 결과를 빠르게 얻을 수 있어, 개발 효율과 소재 품질을 크게 향상시킵니다.

### 픽셀화 및 색상 양자화 처리 플로우

이 툴의 핵심 목표는 AI 생성 이미지를 "고해상도 일러스트 로직"에서 "픽셀 아트 로직"으로 변환하는 것입니다. 이를 위해 클래식한 최근접 이웃 픽셀화·모자이크 효과·유화 스타일 픽셀화·계층 픽셀화 등 다양한 픽셀화 방식을 구현했습니다. 서로 다른 알고리즘은 서로 다른 유형의 입력 소재에 적합하며, 어떤 것은 윤곽 보존에 더 적합하고 어떤 것은 면감 강화에 더 적합합니다. 사용자는 픽셀 블록 크기를 조정하여 서로 다른 정도의 추상화 효과를 얻을 수 있습니다.

색상 제어 측면에서는 **K-Means 클러스터링**·**Median Cut**·**Floyd-Steinberg 디더링**·지각 가중치 강화 버전 등 다양한 색상 양자화 알고리즘을 추가했습니다. 목표는 색상 수를 압축하고 팔레트 경향을 통일하면서 이미지의 주요 구조와 가독성을 최대한 유지하는 것입니다. 이 단계는 픽셀 스타일 통일화에 특히 중요한데, AI 생성 이미지는 중간색과 노이즈 색이 너무 많은 경향이 있어 화면이 "불순하게" 또는 "칙칙하게" 보일 수 있습니다.

### GPU 가속 색상 클러스터링 최적화

실제 제작 환경에서 툴의 사용 가능성을 높이기 위해 성능 병목에 대해 특별히 최적화를 수행했습니다. 색상 양자화의 K-Means 클러스터링은 고해상도 이미지 처리 시 계산량이 많아, 완전히 CPU에 의존하면 처리 속도가 눈에 띄게 느려집니다. 특히 사용자가 여러 파라미터 조합을 시도하거나 배치로 결과를 내보낼 때 대기 비용이 매우 높아집니다.

이에 RAPIDS 기술 스택의 **cuML**과 **cuPy**를 프로젝트에 통합하여 K-Means 클러스터링과 관련 배열 연산을 GPU에서 실행하도록 마이그레이션했습니다. 이를 통해 대형 이미지 처리·고빈도 파라미터 실험·다중 결과 병렬 생성 시 전체적인 응답 속도가 눈에 띄게 향상되었습니다. 여러 픽셀 아트 스타일 방안을 빠르게 검증해야 하는 게임 개발 워크플로우에서 이 가속은 단순히 "더 빠르게 실행"되는 것이 아니라 창작 반복 효율을 직접 향상시킵니다.

설계에서는 CPU 버전도 호환성 대안으로 보존하여 일반 로컬 환경에서도 실행 가능하고, CUDA 조건을 갖춘 Linux / Windows WSL 환경에서는 GPU 모드를 활성화할 수 있도록 하여 사용 편의성과 확장성을 균형 있게 갖추었습니다.

### 엣지 복구 및 이미지 구조 정리

픽셀화와 색상 압축 외에도 AI 이미지에서 가장 흔한 "엣지 오염" 문제를 위해 전용 복구 모듈을 설계했습니다. 이 모듈은 **Canny 엣지 감지**와 커스텀 **이웃 평균 복구 알고리즘**을 기반으로 하여, 윤곽 앨리어싱 이상·엣지 단절·로컬 노이즈·구조 손상 등의 문제를 주로 처리합니다.

사용자는 Canny의 높은/낮은 임계값을 조정하여 엣지 감지 민감도를 제어하고, 팽창·침식 등의 형태학적 연산과 결합하여 엣지 영역 인식 품질을 더욱 최적화할 수 있습니다. 이상으로 인식된 영역에 대해 시스템이 조정 가능한 파라미터의 이웃 평균 방식으로 스무딩과 복구를 수행하여, 원래 손상되거나 부자연스러웠던 엣지 전환을 더욱 통일되게 만듭니다.

이 모듈은 AI 생성 픽셀 이미지에서 "픽셀 아트처럼 보이지만 확대하면 성립하지 않는" 세부 문제 복구에 특히 적합합니다. 다만 엣지 복구는 어느 정도의 흐림을 가져올 수 있으므로 툴 설계에서 픽셀화 모듈과 함께 사용할 것을 강조합니다. 먼저 구조를 정리한 다음 픽셀 블록 관계를 재구성해야 더 자연스럽고 게임 소재 기준에 부합하는 결과를 얻을 수 있습니다.

### 인터랙티브 인터페이스와 다중 결과 비교 워크플로우

사용 문턱을 낮추기 위해 **Gradio**로 프로젝트의 인터랙티브 웹 인터페이스를 구축했습니다. 사용자는 추가 코드 없이 직접 이미지를 업로드하고·픽셀화 방법을 선택하고·색상 양자화 알고리즘을 설정하고·관련 파라미터를 조정하여 출력 결과를 실시간으로 확인할 수 있습니다. 전통적인 명령줄 스크립트 툴에 비해 이 방식은 아트 반복·디자인 검토·빠른 시도에 더 적합합니다.

또한 멀티스레드 처리와 다중 방안 동시 출력 능력도 툴에 설계했습니다. 사용자는 여러 픽셀화 알고리즘과 여러 색상 양자화 전략을 한 번에 선택할 수 있고, 시스템이 서로 다른 스타일의 결과를 병렬로 생성하여 현재 프로젝트의 비주얼 기준에 가장 적합한 버전을 선택하기 위한 횡단 비교를 용이하게 합니다. 이 "결과를 나란히 비교하는" 설계는 파라미터 실험 비용을 크게 줄이고, 툴을 진정한 "현장에서 사용 가능한 보조 툴"로 탈바꿈시킵니다.

### 픽셀 블록 감지 및 규격화 분석 보조

이미지를 직접 처리하는 것 외에도 **Pixel Block Detection Tool**을 추가하여 픽셀 아트 스타일 이미지에서 일반적인 픽셀 블록 크기를 분석합니다. 이 모듈은 이미지의 색상 변화를 스캔하고 윤곽 감지와 결합하여 화면에서 가장 일반적인 색 블록 크기를 추론하고, 현재 이미지의 그리드 구조가 통일되어 있는지를 사용자가 판단하는 데 도움을 줍니다.

이 기능은 픽셀 아트 워크플로우에 매우 실용적입니다. 실제 프로젝트에서 소재는 AI 생성·수작업 드로잉·외주 리소스·과거 소재 라이브러리 등 다양한 출처에서 올 수 있으며 반드시 일관된 픽셀 그리드 기준을 따르지는 않습니다. 픽셀 블록 감지를 통해 사용자는 소재가 현재 프로젝트에 적합한지 더 빠르게 판단하거나, 픽셀화 파라미터 설정을 역으로 안내하는 데 사용할 수 있어 전체 소재 제작 플로우의 일관성을 향상시킵니다.

### 프로젝트 가치 및 실제 의미

본 프로젝트는 개발 기간이 불과 1주일에 불과하지만 매우 현실적인 문제를 해결합니다. **AI가 빠르게 생성한 비주얼 소재를 진정으로 픽셀 게임 제작에 사용 가능한 에셋으로 변환하는 방법**입니다. 인디 게임이나 소규모 팀 프로젝트에서 AI 툴은 초기 컨셉 산출 속도를 크게 높일 수 있지만, 후속 스타일 수정 플로우가 없다면 이러한 소재들은 종종 정식 개발 단계에 직접 진입하기 어렵습니다.

**AI PixelArt Repair Tool**의 의미는 원래는 분산되고 반복적이며 수작업 경험에 의존하는 처리 단계를 툴화·파라미터화·시각화했다는 점에 있습니다. 소재 편집 효율을 향상시킬 뿐만 아니라, 이후 자신의 게임 프로젝트를 위한 "AI 생성 → 자동 최적화 → 에셋 구현"이라는 더 완전한 제작 체인을 구축했습니다. 저에게 이것은 단순한 이미지 처리 툴이 아니라 머신러닝·컴퓨터 비전·게임 개발 워크플로우를 진정으로 결합하는 실천이었습니다.
