## 담당 업무

이 Java 기반의 Discord 챗봇 프로젝트에서 핵심 기능 모듈 개발과 객체 지향 설계 구현을 주로 담당했습니다. 주요 업무 내용은 다음과 같습니다.

* **핵심 기능 개발**: 인증 봇과 성적 조회 봇을 독립적으로 설계·구현하여 사용자의 특정 명령어와 텍스트 메시지에 정확하게 응답하도록 했습니다.
* **아키텍처 설계 및 구현**: 다형성·추상 클래스·인터페이스 등의 객체 지향 프로그래밍 핵심 개념을 깊이 활용하여 추상 기반 클래스 기반의 모듈형 시스템 아키텍처 구축에 참여했습니다.
* **명령어 및 메시지 처리**: 통합과 분리 처리 로직을 담당하여 슬래시 명령어 파싱은 CommandBot이 처리하고, 일상적인 대화와 간단한 인터랙션은 TextBot이 감지·응답하도록 설계했습니다.

## 프로젝트 상세

본 프로젝트는 객체 지향 프로그래밍 수업의 최종 실습 프로젝트로, 기능이 풍부한 Discord 챗봇 개발을 통해 다형성·인터페이스 상속·복잡한 시스템 아키텍처 설계 등의 핵심 프로그래밍 사상을 종합적으로 응용하고 정착시키는 것을 목표로 합니다.

기술 구현에서는 Java와 저수준 통신 라이브러리(Java Discord API)를 기반으로 고도로 모듈화된 아키텍처 설계를 채택했습니다. 시스템 내의 모든 구체적인 기능 모듈(네트워크 지연 테스트·시험 좌석 번호 조회·사용자 등록 관리·신원 확인·성적 확인을 담당하는 봇 등)은 동일한 통일된 추상 기반 클래스를 상속합니다. 서로 다른 유형의 사용자 인터랙션을 정확하게 처리하기 위해 인터랙션 메커니즘을 슬래시 명령어를 파싱하는 CommandBot과 일반 텍스트 메시지를 감지하는 TextBot의 두 가지로 분류했습니다. 이러한 추상화와 다형성 설계는 코드의 재사용성과 유지보수성을 크게 향상시킬 뿐만 아니라, 향후 더 많은 실용적인 기능으로의 확장을 위한 견고한 아키텍처 기반을 마련했습니다.
