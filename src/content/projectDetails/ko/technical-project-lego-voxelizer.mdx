## 담당 업무

Three.js를 활용한 이 웹 기반 3D 시각화 프로젝트에서 복셀화 알고리즘 설계, 렌더링 구현, 핵심 인터랙션 기능 개발을 주로 담당했습니다. 주요 업무 내용은 다음과 같습니다.

* **표면 복셀화 알고리즘 구현**: 삼각형 면적 가중 샘플링 기반의 모델 표면 복셀화 파이프라인을 구현하여 연속 메시 모델을 레고 스타일의 이산 복셀 구조로 변환하고, 두께 확장으로 모델 완성도를 향상시켰습니다.
* **내부 충전 시스템 개발**: Flood Fill 기반의 내부 복셀 인식 및 충전 알고리즘을 구현하여 너비 우선 탐색으로 외부 공간을 마킹하고 더 안정적인 솔리드 복셀 모델을 생성했습니다.
* **이미지 매핑 및 컬러 시스템 설계**: 평면·구면·원통 매핑을 지원하는 텍스처 투영 방식을 개발하여 복셀 모델이 원본 이미지나 텍스처의 색상 정보를 보존할 수 있도록 했습니다.
* **커스텀 셰이더 및 인터랙티브 렌더링**: GLSL로 카툰 픽셀·와이어프레임·레트로 스타일의 3가지 렌더링 효과를 구현하고, Three.js를 활용한 전체 씬 구성과 실시간 인터랙티브 전시를 완성했습니다.

## 프로젝트 상세

본 프로젝트는 복잡한 3D 모델을 레고 블록 스타일의 이산 구조로 변환하여 브라우저에서 실시간으로 시각화하는 웹 기반 3D 레고 복셀화 애플리케이션 구축을 목표로 합니다. 기술 구현에서는 Three.js를 그래픽스 기반 프레임워크로 사용하여 모델 복셀화·내부 충전·이미지 매핑·스타일화 렌더링을 중심으로 완전한 파이프라인을 구축했습니다. 프로젝트는 먼저 삼각형 면적 기반의 표면 샘플링 알고리즘으로 모델 외형을 추출하고 두께 처리와 결합하여 비교적 완전한 복셀 셸을 생성합니다. 이후 Flood Fill 알고리즘으로 닫힌 구조의 내부 공간을 인식하여 모델을 더욱 실체화합니다. 시각적 표현을 강화하기 위해 다양한 텍스처 매핑 방식과 커스텀 GLSL 셰이더도 구현하여 생성 결과가 기하 구조 특성을 유지하면서도 풍부한 색상과 스타일 표현을 가질 수 있도록 했습니다. 본 프로젝트는 3D 지오메트리 처리·인터랙티브 렌더링·스타일화 시각화에서 WebGL과 Three.js의 응용 능력을 보여줍니다.
