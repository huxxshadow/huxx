## 담당 업무

이 기술형 렌더링 프로젝트에서 **프로시저럴 잔디 생성 파이프라인**과 **바람장 잔디 재질 시스템**의 설계 및 구현을 주로 담당하여, UE5의 PCG 워크플로우·베지어 곡선 기반 잔디 모델링·실시간 바람장 애니메이션 표현을 중심으로 개발했습니다. 구체적인 업무 내용은 다음과 같습니다.

- **잔디 생성 시스템 설계**: UE5의 **PCG(Procedural Content Generation)** 모듈을 기반으로 대규모 잔디 배포 플로우를 설계하여 지형 표면에서의 잔디 프로시저럴 생성·밀도 필터링·다양화 분포 제어를 구현했습니다.
- **잔디 셰이더 구조 구축**: **베지어 곡선**의 형태 제어 로직을 기반으로 잔디 재질을 구축하여 단일 잔디 줄기의 너비·높이·굴곡도·끝부분 수렴 효과를 파라미터로 조절할 수 있도록 했습니다.
- **바람장 애니메이션 표현 설계**: 잔디 재질 계산에 바람장 교란을 도입하여 잔디 줄기가 실시간 렌더링에서 자연스러운 흔들림·층별 오프셋·연속적인 변화를 만들어내도록 하여 씬의 동적 표현력을 강화했습니다.
- **재질 파라미터 조정 및 성능 최적화**: 잔디 수량·재질 복잡도·실시간 렌더링 비용 간의 균형을 취하여 대규모 잔디 씬에서의 시각적 품질과 실행 효율을 최적화했습니다.
- **프로시저럴 시스템과 재질 시스템 연계**: PCG 배포 결과와 잔디 재질 파라미터를 결합하여 서로 다른 구역의 잔디가 방향·형태·밀도·동적 효과 면에서 더 강한 통일성과 제어 가능성을 갖추도록 했습니다.

## 프로젝트 상세

*PCG 베지어 곡선 바람장 잔디*는 **프로시저럴 식생 생성**과 **실시간 바람장 시뮬레이션**에 특화된 기술형 렌더링 프로젝트입니다. 핵심 목표는 Unreal Engine 5에서 파라미터 제어 능력·시각적 자연스러움·실시간 성능의 균형을 갖춘 잔디 생성 시스템을 구축하는 것입니다. **PCG 워크플로우**로 잔디의 대규모 배포 로직을 담당하고, **베지어 곡선 잔디 셰이더**로 단일 잔디 줄기의 형태 구축과 바람장 구동을 완성하여, 씬이 거시적 레벨의 분포 조직 능력과 미시적 레벨의 동적 표현 세부 사항을 모두 갖추도록 했습니다.

### UE5 PCG 프로시저럴 잔디 생성

잔디 생성 부분에서 **UE5 PCG 모듈**을 기반으로 완전한 프로시저럴 배포 플로우를 구축했습니다. 시스템은 먼저 지형 표면에서 기본 포인트 세트를 샘플링하고, 밀도 필터링·속성 노이즈·회전 지터·다양한 Static Mesh Spawner를 결합하여 배포 결과를 더욱 제어합니다. 이 방식으로 잔디 줄기가 대규모 씬 전체에서 더 자연스러운 밀도 변화·방향 차이·구역별 레이어링을 형성하여 기계적으로 반복되는 타일링 효과가 나타나지 않도록 했습니다.

이 PCG 플로우는 또한 높은 수준의 파라메트릭 편집도 지원합니다. 예를 들어 샘플링 밀도·필터링 로직·속성 쓰기 규칙을 조정하여 커버리지 범위·클러스터링 경향·로컬 변화 특성을 빠르게 변경할 수 있습니다. 이로써 잔디 시스템이 단일 씬에 적응할 수 있을 뿐만 아니라 서로 다른 지형 유형·아트 스타일·성능 예산에서도 유연하게 재사용할 수 있어, 대규모 실시간 환경 제작을 위한 안정적인 기술 기반을 제공합니다.

### 베지어 곡선 잔디 셰이더와 바람장 표현

단일 잔디 줄기의 표현에서 **베지어 곡선** 방식으로 잔디 재질 구조를 설계하여, 잔디 줄기가 고정된 메시 형태에만 의존하지 않고 파라미터를 통해 전체적인 실루엣과 굴곡 경향을 더 유연하게 제어할 수 있도록 했습니다. 재질 레벨에서 잔디 줄기의 높이·너비·뿌리에서 잎 끝까지의 수렴 관계·전체적인 굽힘 자세를 통일적으로 조정할 수 있어, 더 풍부한 레이어감과 생동감 있는 잔디 줄기 외관을 구축합니다.

이를 바탕으로 바람장 교란을 재질 계산 로직에 더 통합하여 잔디 줄기가 시간이 지남에 따라 연속적인 흔들림과 방향 오프셋을 만들어내도록 했습니다. 바람장은 단순한 일정 방향 이동이 아니라 잔디 줄기의 서로 다른 위치에서의 가중치 차이를 결합하여 뿌리 부분은 비교적 안정적으로 유지하고 잎 끝 부분은 더 뚜렷한 동적 반응을 보이도록 하여, 실제 식생의 바람 수용 효과에 더 가까운 표현을 실현합니다. 최종적으로 이 재질 시스템은 실시간 성능을 확보하면서도 근거리 관찰 시에도 강한 세부 표현력과 자연스러운 동적 감각을 실현했습니다.

### 파라메트릭 제어와 실시간 렌더링 균형

본 프로젝트의 또 다른 중점은 **파라메트릭 제어 능력**과 **실시간 실행 성능** 사이의 적절한 균형을 찾는 것이었습니다. PCG 배포 레벨(포인트 생성 및 인스턴스 배치)이든 재질 레벨(곡선 제어 및 바람장 애니메이션)이든 시각적 품질과 씬 오버헤드 간의 트레이드오프는 피할 수 없습니다. 이를 위해 개발 과정에서 잔디 밀도·인스턴스 레이어링·재질 노드 복잡도·바람장 업데이트 방식을 지속적으로 조정하여 허용 가능한 성능 비용 내에서 충분히 풍부한 동적 세부 사항을 유지하고자 했습니다.

최종 결과는 기술적 목표를 충족합니다. 잔디 씬은 PCG를 통해 대면적 지형으로 빠르게 확장할 수 있고, 한편으로 단일 잔디 줄기는 강한 동적 표현력과 형태 제어 능력을 갖추어, 잔디 시스템 전체가 기술 쇼케이스에 적합할 뿐만 아니라 실제 프로젝트 환경 제작으로의 확장 가능성도 갖추고 있습니다.
