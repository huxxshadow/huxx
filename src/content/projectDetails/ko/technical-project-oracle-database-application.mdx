## 담당 업무

4인으로 구성된 데이터베이스 관리 시스템 팀 프로젝트에서 팀 리더·애플리케이션 개발자·데이터베이스 설계자를 담당했습니다. 주요 업무 내용은 다음과 같습니다.

* **데이터베이스 아키텍처 설계**: 시스템의 개념 설계와 논리 설계를 주도하고, 핵심 비즈니스 프로세스의 개체-관계 다이어그램(ERD)을 처음부터 작성하여 데이터 중복을 효과적으로 줄이는 정규화된 관계형 데이터베이스 테이블로 엄밀하게 변환했습니다.
* **백엔드 로직 및 데이터 일관성 유지**: 핵심 SQL 스크립트를 작성하여 테이블 구조를 구축하고, 항공편 예약과 취소 등의 복잡한 비즈니스 시나리오에서 데이터 일관성과 무결성을 보장하는 PL/SQL 트리거(Triggers)를 개발했습니다.
* **애플리케이션 계층 개발 및 통합**: Java와 JDBC API를 사용하여 애플리케이션 계층과 Oracle 데이터베이스 간의 저수준 인터랙션을 구현하고, 항공편 검색·좌석 예약·동적 할인 요금 계산 등의 핵심 기능을 성공적으로 연결했습니다.

## 프로젝트 상세

본 프로젝트는 홍콩 침례 대학교 컴퓨터공학과 데이터베이스 관리 시스템 수업의 최종 실습 프로젝트로, 엔드-투-엔드 항공편 예약 시스템을 설계·구현하는 것을 목표로 합니다. 기술적으로 시스템 백엔드는 Oracle 데이터베이스로 구축하고, 애플리케이션 계층은 Java로 개발하여 JDBC를 통한 양방향 데이터 인터랙션을 구현했습니다. 전체 개발 라이프사이클 동안 팀은 데이터베이스 설계의 표준 정규형을 엄격히 준수했습니다. 먼저 항공편·고객·주문 등의 핵심 개체를 명확히 하여 ERD 모델링을 완성하고, 이후 기본키·외래키 정의와 데이터베이스 정규화 처리를 수행하며, 마지막으로 기반 아키텍처와 상위 비즈니스 로직을 깊이 결합했습니다. 티켓 시스템의 엄밀성을 보장하기 위해 데이터베이스 내에 PL/SQL 트리거를 배포하여 항공편 잔여 좌석 상태를 실시간으로 동기화하고, 환승 횟수에 따라 단계별 할인을 자동으로 계산하도록 했습니다. 본 프로젝트는 요구사항 분석·데이터베이스 논리 설계부터 최종 애플리케이션 통합까지의 전체 파이프라인을 완벽히 아우르며, 데이터베이스 이론과 엔지니어링 실무의 종합적인 검증입니다.
