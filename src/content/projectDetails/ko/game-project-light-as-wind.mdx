## 담당 역할

USC Games 학생 다섯 명이 That Game Jam을 위해 팀을 꾸려 Unity 6로 2주 만에 만들었습니다. 저는 디렉터를 맡았고, 게임 디자인, 리드 프로그래밍, 테크니컬 아트도 담당했습니다.

* **디렉팅과 디자인**: 전체 플레이와 감정의 흐름을 정하고, 10개 스테이지를 하나의 여정으로 엮었습니다.
* **절차적 생물**: 게임 속 생물 시스템을 모두 작성했습니다. 불가사리, 황새치, 게를 비롯한 바다 생물에는 키프레임 애니메이션이 없고, 모든 동작은 코드로 실시간 생성됩니다.
* **픽셀 렌더링**: 3D 픽셀 아트를 위해 렌더 파이프라인을 직접 만들어 URP를 대체했고, 카메라가 움직여도 픽셀이 안정적이고 깜빡이지 않게 했습니다.
* **도구**: 레벨 편집 도구와 자동 테스트·녹화 도구를 만들어, 다섯 명이 2주 안에 10개 스테이지를 완성할 수 있게 했습니다.
