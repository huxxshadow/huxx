## 담당 역할

**게임 + AI** 분야의 개인 프로젝트로, 《테라리아》에서 플레이어를 따라다니며 전투를 돕는 AI 팀원을 만들었습니다. 전통적인 행동 트리를 뼈대로 삼아 대부분의 결정 노드를 Jev 모델에 맡기고, 트리는 흐름 제어, 즉각 반응, 실패 시 대체 처리를 담당합니다.

- **의사결정 아키텍처**: "LLM 대뇌 + Jev 소뇌 + 행동 트리"의 계층 구조를 설계하고, 어떤 게이트를 Jev가 판단하고 어떤 것을 코드의 반사로 남길지 정했으며, 이 분담이 실시간 게임에서 성립하기 위한 규칙을 정리했습니다.
- **Jev 노드**: 질문, 모델이 보는 상태 스냅샷, 대칭적인 선택지 서술, 신뢰도 임계값, 그리고 300 ms짜리 답이 16 ms 틱 안에서 살아남게 하는 비동기 배관을 설계했습니다.
- **고전 계층**: 점프와 비행 궤적을 게임 물리에서 추적하는 경로 탐색, 예측 조준, 회피, 절대 좁혀지지 않는 보스 거리 링.
- **대뇌 계층(LLM)**: ChatGPT가 보스별 생존 매뉴얼과 채굴 계획을 생성해, 상위 전략으로서 각 Jev 노드의 판단 조건과 상태 스냅샷에 반영합니다. 키 입력을 직접 지시하지는 않습니다.

## 설계 방향

전체는 "대뇌 + 소뇌"의 계층 구조입니다. LLM이 전략을, Jev가 판단을, 행동 트리와 코드가 실행을 맡습니다.

**문제: 사람이 짜 둔 조건 노드.** 전통적인 행동 트리는 상태 선택을 사람이 미리 짜 둔 조건에 크게 의존합니다. "후퇴해야 하나", "어떤 무기를 쓸까" 같은 판단을 하나하나 고정 규칙으로 미리 작성해야 해서, 전투 상황이 복잡해질수록 번거롭고 경직됩니다.

**1계층 · Jev 소뇌: 판단 노드 대체.** 복잡한 상태를 종합적으로 판단해야 하는 작은 노드들을 Jev로 대체합니다. 그 추론 속도를 활용해 각 노드가 런타임에 현재 상황을 직접 판단하고, 행동 트리의 명확한 흐름 구조는 유지합니다.

**2계층 · LLM 대뇌: 조건의 동적 설정.** Jev 노드 자체도 고정되어 있지 않습니다. 상위 LLM이 전체 전황과 장기 목표를 파악해 각 Jev 노드에 설정된 조건을 동적으로 조정하므로, 같은 트리라도 보스와 페이즈에 따라 다른 선택을 합니다.

| 계층 | 역할 | 담당 | 갱신 빈도 |
| --- | --- | --- | --- |
| LLM(ChatGPT) | 대뇌 | 전황과 목표를 파악해 Jev 노드의 조건 설정 | 보스마다 한 번, 채굴 계획은 12초마다 |
| Jev 노드 | 소뇌 | 복잡한 상태를 빠르게 판단 | 답변당 약 300 ms |
| 행동 트리와 코드 | 실행 | 흐름 제어, 즉각 반응, 실패 시 대체 처리 | 초당 30 tick |

## Jev 노드 해부

Jev 노드는 전통적인 수치 비교가 아니라 의미 기반 판단으로 동작하는 행동 트리의 게이트 노드입니다. 각 노드는 다섯 부분으로 구성됩니다:

**상태 스냅샷**: 코드는 현재 결정에 필요한 구조화된 정보만 추출합니다. 예를 들어 체력, 최근 피격 여부, 보스와의 거리와 접근 속도, 방향별 이동 가능한 공간 등이며, 불필요한 전역 상태를 모델에 넘기지 않습니다.

**대칭적인 선택지**: 각 선택지에 이점과 대가를 함께 적어 표현상의 편향을 줄입니다. 초기 테스트에서는 원거리 무기의 장점만 강조해 모델이 여섯 번 연속으로 활을 골랐지만, 무기별 사거리와 제약을 보완하자 다섯 번 중 네 번 기대한 선택을 했습니다.

**타입이 있는 출력과 개별 임계값**: 다지선다 판단은 선택지별 확률 분포와 전체 신뢰도를, 이진 판단은 조건이 성립할 확률을 반환합니다. 임계값은 노드별 실측 결과에 따라 따로 정하며, 예를 들어 무기 선택은 0.35, "지금 물약을 쓸지"는 0.5를 사용합니다.

**비동기 실행**: 행동 트리는 초당 30회 실행되지만 모델 응답에는 약 300밀리초가 걸립니다. 노드는 메인 루프를 막지 않고 해당 채널의 최신 결과를 읽으며, 상태 스냅샷이 바뀌면 백그라운드에서 다시 요청하고 채널마다 동시에 하나의 요청만 실행되도록 제한합니다.

**규칙 기반 대체 처리**: 결과가 없거나 신뢰도가 부족하면 가장 피해량이 높은 무기 선택, 체력 임계값에 따른 물약 사용, 점수 기반 출구 선택 같은 결정적 규칙으로 돌아갑니다. 이를 통해 AI 판단이 행동의 질을 높이면서도 기본 스크립트의 안정성 아래로 떨어지지 않도록 했습니다.
