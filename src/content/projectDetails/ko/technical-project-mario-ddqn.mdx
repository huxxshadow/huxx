## 담당 업무

이 TensorFlow 기반의 강화학습 프로젝트에서 알고리즘 모델 설계와 핵심 훈련 파이프라인 구현을 주로 담당했습니다. 주요 업무 내용은 다음과 같습니다.

* **심층 Q 네트워크 구축**: TensorFlow와 Keras를 사용하여 다층 합성곱 신경망(CNN)을 포함한 이중 심층 Q 네트워크(DDQN)를 구축했습니다. 실시간 의사결정을 위한 Online 네트워크와 학습 안정화를 위한 Target 네트워크가 포함됩니다.
* **강화학습 정책 구현**: ε-greedy 탐색 기반의 행동 선택 정책을 개발하고, 게임 초기의 탐색과 후기의 정책 활용 간의 균형을 맞추는 동적 감쇠 메커니즘을 구현했습니다.
* **경험 재생 및 그래디언트 최적화**: 과거 전환 데이터를 저장·무작위 샘플링하는 Experience Replay 버퍼를 구축하고, Huber 손실과 Adam 옵티마이저를 결합한 맞춤형 그래디언트 계산·역전파 훈련 단계를 설계했습니다.
* **모델 동기화 및 엔지니어링**: Target 네트워크 가중치의 정기 동기화 메커니즘을 구현하고, 단계별 자동 모델 가중치 저장과 훈련 로그 기록 기능을 완성했습니다.

## 프로젝트 상세

본 프로젝트는 강화학습을 통해 마리오가 자율적으로 스테이지를 클리어하는 능력을 갖추게 하는 것을 목표로 합니다. 기술적으로는 연속적인 게임 화면 픽셀을 다채널 입력 데이터로 직접 받아 다층 CNN으로 공간 특징을 추출·평탄화하고, 최종적으로 현재 상태에서 마리오의 각 행동의 Q 값을 출력하는 이중 심층 Q 네트워크(DDQN) 아키텍처를 구축했습니다. 심층 강화학습에서 흔히 발생하는 훈련 불안정 문제를 해결하기 위해 경험 재생(Experience Replay) 메커니즘을 도입하여 샘플 데이터 간의 시간적 상관성을 끊고, 네트워크를 Online과 Target의 두 독립 모델로 분리했습니다. Online 네트워크는 실시간 행동 선택과 파라미터 업데이트를 담당하고, Target 네트워크는 일정 훈련 스텝마다 파라미터를 동기화합니다. ε-greedy의 동적 탐색률 감쇠 및 Huber 손실 함수의 스무딩 제약과 결합하여, 모델 전체가 복잡한 플랫폼 점프 환경에서 최적의 클리어 전략과 행동 조합을 효율적이고 안정적으로 학습할 수 있습니다.
