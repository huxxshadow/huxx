## V2 · 프랙탈 표면 융합 DCC 툴

프랙탈 표면 융합 DCC 툴은 임의의 3D 모델을 프랙탈 기하와 융합하고, 디테일이 끝없이 펼쳐지는 프랙탈 표면을 브라우저에서 실시간으로 렌더링하며, GPU 지오메트리 처리를 통해 바로 제작에 쓸 수 있는 고해상도 워터타이트 메시로 내보냅니다. 이번 버전은 Blender 애드온 Fractal Machine의 노드 네트워크를 참고해 프랙탈 필드, 융합 방식, 머티리얼 시스템, 메시 내보내기를 Three.js로 처음부터 다시 만들었고, 'Blender에서 오래 베이크하던 작업'을 '브라우저에서 실시간으로 조정하고 클릭 한 번으로 내보내는' 워크플로로 바꿨습니다.

### 담당 업무

개인 프로젝트로, 렌더러부터 툴체인까지 모두 혼자 개발했습니다.

- **프랙탈 필드와 융합**: Mandelbulb 거리 추정과 Blender 밀도 필드 두 가지 프랙탈 필드를 구현하고, 모델의 부호 있는 거리 필드를 GPU에서 베이크했습니다. 셸 랩, 공간 워프, SDF 블렌드, 불리언, 표면 카빙 등의 융합 방식을 설계했습니다.
- **무한 디테일의 실시간 렌더링**: 풀스크린 레이마칭 셰이더, 정지 시 프로그레시브 슈퍼샘플링, 소프트 섀도, 이미지 기반 조명, 스튜디오 바닥으로 어떤 배율에서도 프랙탈 디테일을 선명하게 유지합니다.
- **지오메트리 처리와 내보내기**: 블록 단위 GPU 샘플링과 블록 간 정점을 용접하는 Marching Cubes로 암시적 프랙탈 표면을 고해상도 워터타이트 메시로 변환하고, GLB / PLY / STL로 Blender 등 DCC 툴에 바로 넘깁니다.
- **머티리얼과 툴화**: 애드온의 프랙탈 셰이딩을 재현하고 서브서피스 스캐터링, 투과, 클리어코트, 박막 간섭, 자체 발광을 추가했습니다. 씬 프리셋, 파라미터 파일, 중·영 UI, 4K 오프라인 녹화도 지원합니다.

### 모델과 프랙탈의 융합

융합의 핵심은 두 거리 필드의 조합입니다. 불러온 모델은 먼저 GPU에서 3D 부호 있는 거리 필드로 베이크되고(three-mesh-bvh로 최근접점을 구하고 7개 광선의 투표로 안팎을 판정), 프랙탈은 반복 공식으로 정의된 암시적 필드로 다룹니다.

기본 **셸 랩** 모드는 프랙탈 공간을 모델 표면에 '입힙니다'. 모델 근처의 각 점을 중심에서 뻗는 방향이나 표면 법선 방향을 따라 프랙탈 구의 한 껍질에 매핑하므로, 프랙탈 무늬가 모델의 윤곽을 따라 자라납니다. 융합 정도는 0에서 1까지 연속적으로 변하며, 중간 상태에서는 원래 형태를 유지하면서 프랙탈 디테일이 점차 드러납니다. 이 밖에 애드온을 재현한 공간 워프, 부드러운 SDF 블렌드, 교집합 / 차집합 / 합집합 불리언, 표면 카빙도 지원합니다.

### 무한 디테일의 실시간 렌더링

프랙탈 표면은 메시가 아니라 어떤 스케일에서도 계산할 수 있는 수학 함수이므로, 렌더링은 셰이더 안에서 직접 이루어집니다. 풀스크린 사각형이 픽셀마다 광선을 쏘고, 거리 추정으로 표면에 다가갑니다. Mandelbulb는 해석적 거리 추정을 사용하므로 카메라가 가까워질수록 디테일이 계속 펼쳐집니다. Blender 밀도 필드 모드는 3D 텍스처로 베이크한 뒤 트라이큐빅 B-스플라인 보간으로 샘플링해, 복셀 블록감 없이 매끄럽고 연속적인 표면을 유지합니다.

카메라가 멈춰 있을 때는 Halton 수열로 픽셀을 서브픽셀 단위로 지터링하며 프레임을 누적하고, 면광원의 위치도 지터링해 안티에일리어싱과 부드러운 소프트 섀도를 얻습니다. 드래그 중에는 해상도를 자동으로 낮춰 조작을 부드럽게 유지합니다. 조명은 키 라이트, 림 라이트, 이미지 기반 환경 반사, 스튜디오 바닥으로 구성됩니다.

### 머티리얼과 라이팅

머티리얼 시스템은 먼저 애드온의 프랙탈 셰이딩을 재현했습니다. 프랙탈 반복 중의 궤도 정보로 Color Map을 계산하고, 앰비언트 오클루전과 범프를 결합해 베이스 컬러, 메탈릭 강조색, 틈새 색을 표면의 각 층에 배분함으로써 애드온 특유의 그레이·골드 질감을 만듭니다.

그 위에 여러 표면 레이어를 더했습니다. 서브서피스 스캐터링, 굴절 방향을 따라 내부를 마칭하며 Beer-Lambert 법칙으로 흡수하는 투과, 클리어코트, 박막 간섭에 의한 무지갯빛, 틈새나 색띠를 따라 빛나는 자체 발광입니다. 이를 조합해 비취, 무지갯빛 갑각, 용암 균열, 유약 도자기, 블랙 골드, 크롬과 골드, 녹청 등의 프리셋을 만들었고, 모든 파라미터를 실시간으로 조정할 수 있습니다.

### 지오메트리 처리와 고해상도 내보내기

실시간 프리뷰와 함께 툴의 또 다른 축은 암시적 프랙탈 표면을 실제 지오메트리로 바꾸는 작업입니다. 내보낼 때 계산 영역을 129³ 블록으로 나누고, GPU에서 블록마다 거리 필드를 샘플링한 뒤 표면이 있는 블록에만 Marching Cubes를 적용합니다. 블록 경계에서는 정점을 용접해 틈 없는 워터타이트 메시를 얻습니다. 그리드는 최대 2048³까지 지원해 눈에 보이는 프랙탈 디테일을 충분히 보존합니다.

법선과 정점 컬러는 같은 셰이더로 GPU에서 계산하므로 내보낸 결과가 프리뷰와 일치합니다. 등가면을 따라 표면에 두께를 주거나, 원본 모델 크기로 되돌리거나, GLB를 그레이 베이스와 골드 강조의 두 머티리얼로 나눌 수도 있어 Blender에 불러와 바로 렌더링이나 3D 프린팅에 쓸 수 있습니다.

### 실제 시연

툴은 브라우저에서 동작합니다. 사이드 패널에서 씬 프리셋(모델 + 프랙탈 + 융합 설정)을 바꾸고, 직접 만든 GLB / OBJ / STL / PLY 모델을 드래그 앤 드롭으로 불러오고, 파라미터 파일을 저장·불러오며, 프랙탈·융합·머티리얼의 모든 파라미터를 실시간으로 조정할 수 있습니다. UI는 중국어와 영어 전환을 지원합니다. 소개 영상도 툴이 직접 녹화했습니다. 오프라인 렌더러가 고정 해상도로 프레임마다 샘플을 누적하고, 물체의 바운딩 포인트로 카메라 거리를 계산해 오빗 중에도 물체가 항상 화면 안에 온전히 들어오도록 합니다.

### 담당 업무

WebGL과 Three.js를 활용한 이 프랙탈 모핑 프로젝트에서 프랙탈 렌더링 알고리즘 설계, 모핑 로직 구현, 전체 시각화 파이프라인 개발을 주로 담당했습니다. 주요 업무 내용은 다음과 같습니다.

* **레이마칭 렌더링 구현**: Signed Distance Function(SDF)에 기반한 레이마칭 렌더링 파이프라인을 구축하여 프로시저럴 지오메트리와 프랙탈 구조의 실시간 표면 교차 및 시각화를 구현했습니다.
* **Mandelbulb 프랙탈 모델링**: 반복 공식·구면 좌표 변환·도함수 누적을 통해 3D Mandelbulb 프랙탈의 거리 추정 함수를 구현하여 자기 유사적 세부 구조를 가진 3D 프랙탈 형태를 생성했습니다.
* **모핑 시스템 개발**: 전통적인 3D 모델과 Mandelbulb 프랙탈 사이의 부드러운 모핑 방식을 설계·구현하고, 수학적 레벨에서 서로 다른 SDF를 혼합하여 연속적인 중간 형태를 생성했습니다.
* **인터랙션 및 파라미터 제어**: Three.js를 활용한 인터랙티브 웹 기반 전시 환경을 구축하고, 프랙탈 반복 횟수·변형 강도·부드러움 등의 파라미터 조정을 지원하여 시각화 품질과 실험적 표현력을 향상시켰습니다.


### 프로젝트 상세

본 프로젝트는 전통적인 3D 모델과 수학적 프랙탈 사이의 연속적인 형태 전환을 탐구하고, 웹 기반 인터랙티브 렌더링을 통해 이 기하학적 표현 방식의 변화 과정을 시각화하는 것을 목표로 합니다. 기술 구현에서는 Signed Distance Function 기반의 레이마칭 방식을 핵심 렌더링 수단으로 채택하여 프로그래밍 방식으로 정의된 복잡한 기하 구조의 실시간 교차 및 셰이딩을 가능하게 했습니다. 프랙탈 부분은 Mandelbulb 구조를 기반으로 구현했으며, 3D 만델브로트 집합의 3차원 구면 좌표에서 점에 거듭제곱 회전과 반복을 적용하여 풍부한 자기 유사적 세부 구조를 가진 3D 프랙탈 형태를 생성합니다. 모델과 프랙탈 사이의 부드러운 전환을 실현하기 위해 프로시저럴 모델의 SDF와 Mandelbulb 거리 필드를 수학적 레벨에서 혼합하고, smooth minimum과 선형 보간을 결합한 연속적인 모핑 프로세스를 구축했습니다. 중간 상태는 원본 모델의 실루엣을 유지하면서 점차 프랙탈 세부 구조를 드러냅니다. 본 프로젝트는 복잡한 시각 생성과 인터랙티브 3D 예술 표현에서 WebGL·Three.js·프로시저럴 지오메트리 기술의 응용 가능성을 보여줍니다.
