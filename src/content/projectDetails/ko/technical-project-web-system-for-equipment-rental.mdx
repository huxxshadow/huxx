## 담당 업무

이 2개월간의 개인 풀스택 개발 프로젝트에서 요구사항 분석·시스템 설계부터 프론트엔드/백엔드 구현·배포 테스트까지의 완전한 개발 프로세스를 독립적으로 완성했습니다. 주요 업무 내용은 다음과 같습니다.

* **시스템 아키텍처 설계 및 풀스택 개발**: 기기 대여 관리 시스템의 프론트엔드/백엔드 아키텍처 전체를 구축하는 것을 담당했습니다. 프론트엔드는 Vue 3·Vue Router·Bootstrap 5로 반응형 인터페이스를 구축하고, 백엔드는 Node.js·Express.js·MongoDB로 RESTful API와 데이터 영속성을 구현했습니다.
* **접근 제어 및 인증 메커니즘 구현**: **JWT** 기반의 신원 인증과 역할 기반 접근 제어 메커니즘을 설계·구현하여 관리자와 일반 사용자의 작업 경계를 구분하고, 기기 관리·사용자 관리·대여 프로세스의 보안을 확보했습니다.
* **기기 및 사용자 관리 모듈 개발**: 기기 정보 관리·사용자 정보 관리·기기 검색·상태 추적·대여 기록 관리 등의 핵심 비즈니스 기능을 구현하여 관리자가 시스템 자원을 중앙화하여 관리할 수 있도록 지원했습니다.
* **대여 플로우 및 캘린더 시각화 설계**: 기기 대여 및 반납의 완전한 비즈니스 플로우를 개발하고, 기기 대여 현황과 시간 충돌을 표시하는 캘린더 뷰를 통합하여 기기 스케줄링의 시각화와 관리 가능성을 향상시켰습니다.
* **프론트엔드/백엔드 연동 및 인터랙션 최적화**: API 연동·폼 유효성 검사·오류 상태 처리·인터랙션 경험 최적화를 담당하여 다양한 기기에서의 시스템 사용 가능성과 조작 원활함을 확보했습니다.
