## 담당 업무

이 1개월간의 Android 애플리케이션 개발 프로젝트에서 주요 기능의 설계와 구현을 독립적으로 담당했습니다. 구체적인 업무 내용은 다음과 같습니다.

* **모바일 아키텍처 설계 및 애플리케이션 개발**: **MVVM** 아키텍처를 적용하여 Kotlin으로 전체 애플리케이션을 개발하고, 페이지 로직·상태 관리·데이터 플로우를 구성하여 명확하고 유지보수하기 쉬운 코드 구조를 확보했습니다.
* **UI 설계 및 인터랙션 구현**: **Jetpack Compose**를 사용하여 모던 모바일 인터페이스를 구축하고, 기기 탐색·검색·예약·로그인·회원가입 등의 핵심 화면을 구현하며, 모바일 사용 습관에 최적화된 조작 흐름을 정비했습니다.
* **백엔드 API 통합 및 데이터 관리**: 백엔드 기기 관리 API와 연동하여 사용자 인증·기기 조회·장소 필터링·예약 제출 등의 기능을 구현하고, 저장소 계층을 통해 네트워크 요청과 데이터 처리 로직을 통일적으로 캡슐화했습니다.
* **예약 플로우 및 오류 처리 개발**: 날짜 범위 선택·충돌 처리·입력 유효성 검사·네트워크 오류 피드백을 포함한 기기 예약의 완전한 비즈니스 플로우를 구현하여 애플리케이션의 안정성과 사용성을 향상시켰습니다.
* **모바일 사용자 경험 최적화**: 기기 목록의 페이지네이션 스크롤 로딩을 구현하고, 인터페이스 피드백·오류 메시지·상태 전환을 최적화하여 실제 사용에서 더 매끄럽고 직관적인 애플리케이션 경험을 실현했습니다.
