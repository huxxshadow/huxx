## 담당 업무

3인으로 구성된 머신러닝 팀 프로젝트에서 팀 리더 및 데이터 사이언티스트를 담당했습니다. 주요 업무 내용은 다음과 같습니다.

* **오디오 특징 엔지니어링**: 신호 처리 라이브러리로 대량의 오디오 데이터를 전처리하고, 시간 영역·주파수 영역·혼합 시간-주파수 영역의 핵심 특징을 추출하며, 멜 스펙트로그램(Mel Spectrograms)을 머신러닝 모델의 핵심 입력으로 변환했습니다.
* **데이터 시각화 분석**: 서로 다른 음악 장르의 데이터 분포와 음향 특징에 대한 심층 시각화 분석을 수행하여 후속 특징 선택과 모델 구축에 직관적인 데이터 근거를 제공했습니다.
* **모델 구축 및 평가**: 복잡한 오디오 특징의 효율적인 분류를 위해 다양한 클래식 머신러닝 알고리즘(의사결정나무·K-최근접 이웃·랜덤 포레스트 등)을 적용하고 비교했습니다.
* **하이퍼파라미터 최적화**: 자동화된 하이퍼파라미터 최적화 프레임워크(Optuna 등)를 도입하여 머신러닝 모델의 핵심 파라미터를 체계적으로 튜닝하고, 최종 분류기의 정확도와 일반화 능력을 크게 향상시켰습니다.

## 프로젝트 상세

본 프로젝트는 신호 처리 기술과 머신러닝 알고리즘을 통해 음악 장르를 자동으로 인식하는 지능형 시스템을 개발하는 것을 목표로 합니다. 디지털 음악이 고도로 보급된 현대에 주요 스트리밍 플랫폼들은 자동화된 음악 분류와 검색에 대한 막대한 수요를 가지고 있으며, 본 프로젝트는 음악 정보 검색(MIR) 분야의 핵심 태스크에 대한 실천적 탐구입니다.

기술적으로는 10가지 서로 다른 음악 장르에 걸친 4,500개의 오디오 클립을 포함하는 오픈소스 데이터셋을 사용했습니다. 프로젝트 전반부의 핵심은 오디오 신호의 특징 추출이었으며, 일반적인 시간 영역·주파수 영역 특징 추출에 더해 음악의 본질적 특성을 포착하는 주요 데이터 차원으로서 멜 스펙트로그램으로의 변환을 특별히 수행했습니다. 모델 학습 단계에서는 의사결정나무(Decision Tree)·K-최근접 이웃(KNN)·랜덤 포레스트(Random Forest)를 포함한 다양한 클래식 머신러닝 분류기를 구축하고 비교했습니다.

모델 성능 잠재력을 더욱 끌어내기 위해 자동화된 하이퍼파라미터 최적화 라이브러리로 각 알고리즘에 대한 세밀한 튜닝을 실시했습니다. 최종적으로 테스트 세트에서의 엄격한 평가 결과, 최적화된 머신러닝 모델이 10가지 복잡한 음악 장르의 고정밀 분류에 성공하여 신호 처리 특징과 전통적인 머신러닝 모델의 결합이 오디오 분류 태스크에 효과적임을 입증했습니다.
