## 담당 업무

이 데이터 사이언스 및 머신러닝 기초 알고리즘 탐구 프로젝트에서 알고리즘의 도출과 엔지니어링 구현을 독립적으로 완성했습니다. 주요 업무 내용은 다음과 같습니다.

* **알고리즘 처음부터 구현**: Python과 NumPy 과학 계산 라이브러리를 기반으로 변분 베이지안 가우시안 혼합 모델(VB-GMM)을 처음부터 도출·구현하여 복잡한 확률적 그래픽 모델의 코드 구현을 완성했습니다.
* **변분 추론 로직 구축**: 모델 핵심 반복 과정에서 평균·공분산·디리클레 분포 파라미터(Alpha)·정밀도 파라미터(Beta)의 변분 업데이트 방정식을 구현했습니다.
* **수치 계산 최적화**: Cholesky 분해 기반의 정밀도 행렬 계산 방법을 도입하여 고차원 행렬 역행렬 계산에서의 특이값 문제를 효과적으로 회피하고 알고리즘의 계산 효율과 수치 안정성을 대폭 향상시켰습니다.
* **수렴 판정 및 시각적 평가**: 증거 하한(ELBO) 기반의 자동 수렴 판정 메커니즘을 설계하고, 가우시안 신뢰 타원을 그려 자체 구현 알고리즘과 Scikit-learn 모델의 피팅 성능을 직관적으로 비교하는 평가 모듈을 개발했습니다.

## 프로젝트 상세

본 프로젝트는 변분 베이지안 가우시안 혼합 모델(VB-GMM)을 수동으로 처음부터 구현하여 비지도 학습과 변분 추론의 기초적인 수학 원리와 엔지니어링 응용을 깊이 탐구하는 것을 목표로 합니다. 기술적으로 시스템은 먼저 6개의 서로 다른 분포 특성을 가진 다변량 가우시안 합성 데이터셋을 생성하고, KMeans 또는 랜덤 초기화 전략으로 초기 책임 행렬(Responsibility Matrix)을 구성합니다. 핵심 모델 반복 단계에서 알고리즘은 베이지안 추론 로직을 엄격히 따르며 현재 책임 행렬을 기반으로 각 가우시안 컴포넌트의 평균·공분산·가중치를 제어하는 Alpha 파라미터·정밀도를 제어하는 Beta 파라미터를 지속적으로 업데이트합니다. 계산 과정의 성능 병목과 행렬 양정부호 문제를 해결하기 위해 Cholesky 분해 기술을 정밀도 행렬 처리에 활용했습니다. 모델의 수렴 조건은 증거 하한(ELBO)의 증분 변화에 엄격히 결부되어, 변화량이 설정 임계값을 하회하면 추론 완료로 판정합니다. 최종적으로 고정밀도 비지도 클러스터링을 실현할 뿐만 아니라, 직관적인 2D 가우시안 타원 시각화를 통해 자체 알고리즘의 피팅 결과를 Scikit-learn 표준 라이브러리의 `BayesianGaussianMixture` 모델과 엄격하게 비교 분석하여 자체 추론 알고리즘의 정확도와 강건성을 충분히 검증했습니다.
