## 담당 업무

프로젝트 멤버로서 **비디오 생성 워크플로우의 설계 및 구현**을 주로 담당하여, 비디오 생성 전 이미지 전처리부터 생성 후 초해상도 및 프레임 보간 최적화까지 두 가지 핵심 단계를 커버했습니다. 구체적인 업무 내용은 다음과 같습니다.

- **비디오 전처리 파이프라인 구축**: 이미지 향상·밝기와 대비 조정·색상 균형·해상도 표준화를 포함한 입력 이미지 전처리를 수행하여 후속 비디오 생성 모듈에 더 명확하고 안정적이며 포맷이 통일된 입력을 제공했습니다.
- **퍼스트-앤-라스트 프레임 가이드 비디오 생성 워크플로우**: **WAN2.2 Base Model**·**CLIP**·**VAE**·**LightX2V LoRA**를 기반으로 첫 번째와 마지막 프레임을 가이드로 하는 비디오 생성 파이프라인을 구축하고, 수미 프레임을 시간적 경계 조건으로 사용하여 긍정/부정 프롬프트와 결합해 비디오 시퀀스를 생성했습니다.
- **비디오 생성 파라미터 설계 및 튜닝 참여**: 샘플링 단계에서 프롬프트 구조·노이즈 분기·추론 스텝 수·의미 제어 방식을 조정하여 동작 연결성·시간적 일관성·시각적 품질에서의 비디오 성능을 최적화했습니다.
- **비디오 후처리의 초해상도 모듈 담당**: 생성된 비디오를 프레임 분할 처리하고 **DiT**와 **VAE** 관련 플로우를 사용하여 프레임 레벨의 선명도를 향상시키고, 흐림·압축 아티팩트·텍스처 부족 문제를 줄였습니다.
- **프레임 보간 및 부드러움 최적화 담당**: **GIMM-VFI**를 사용하여 원본 프레임 사이에 중간 전환 프레임을 생성하여 프레임 간 연속성과 동작의 부드러움을 향상시키고 낮은 프레임 레이트로 인한 떨림을 줄였습니다.
- **완전한 비디오 출력 통합 참여**: 초해상도와 프레임 보간 후 처리된 프레임 시퀀스를 최종 비디오로 재합성하고 원본 오디오와 메타데이터와 통합했습니다.

## 프로젝트 상세

본 프로젝트에서 **비디오 워크플로우 메인라인 부분의 기술 구현**을 주로 담당했습니다. 비디오 생성 전, 이미지 향상·밝기와 대비 보정·색상 균형·해상도 표준화를 포함한 입력 이미지 전처리 파이프라인을 설계·완성했습니다. 이 단계의 목표는 원본 입력의 선명도와 시각적 일관성을 향상시키면서 후속 비디오 생성 모델의 해상도와 포맷 요구사항을 충족시키는 것입니다. 전처리 완료 후, **WAN2.2**를 기반으로 퍼스트-앤-라스트 프레임 가이드 비디오 생성 파이프라인을 구축하고, 텍스트 의미 인코딩에 **CLIP**을, 잠재 공간 매핑에 **VAE**를 사용하며, 더 효율적인 저스텝 추론을 지원하기 위해 **LightX2V LoRA**를 도입했습니다. 수미 프레임을 시간적 경계 조건으로 사용하고 긍정/부정 프롬프트로 씬 내용·카메라 언어·동작 변화를 제어하여 더 일관되고 제어 가능한 비디오 생성 결과를 실현했습니다.

비디오 생성 후 화질 향상과 동작 최적화를 위한 후처리 단계를 담당했습니다. 먼저 생성된 비디오를 프레임 분할하고 **DiT**와 **VAE** 파이프라인을 적용하여 프레임 레벨의 초해상도 재구성을 실시했습니다. 생성 비디오에서 흔히 발생하는 흐림·압축 아티팩트·텍스처 부족 등의 문제를 해결하면서 씬 내용과 스타일의 일관성을 유지했습니다. 이후 **GIMM-VFI**로 프레임 보간을 실시하여 원본 프레임 사이에 중간 프레임을 생성함으로써 재생 시 동작의 부드러움과 시간적 연속성을 향상시키고, 낮은 프레임 레이트 비디오에서 흔히 발생하는 끊김과 점프를 줄였습니다. 최종적으로 초해상도와 프레임 보간 후의 프레임 시퀀스를 비디오로 재합성하고 원본 오디오와 통합하여 선명도·안정성·시청 경험에서 눈에 띄는 향상을 이루었습니다.
