## 담당 업무

이 1년간의 스타트업 수준 IoT 및 AI 프로젝트에서 기술 리더 겸 핵심 개발자로서 기술팀을 이끌어 개념 프로토타입을 상업적 가능성을 가진 스마트 하드웨어 제품으로 전환했습니다. 주요 업무 내용은 다음과 같습니다.

* **핵심 아키텍처 및 풀스택 개발**: 디바이스 측과 서버 측의 전체 아키텍처를 주도적으로 설계·구현하고, 멀티스레드 병렬 처리·프론트엔드/백엔드 양방향 통신·소프트웨어-하드웨어 데이터의 원활한 통합을 독립적으로 개발했습니다.
* **AI 알고리즘 및 비주얼 트래킹 통합**: 음성 인식·대규모 언어 모델(ChatGPT) 기반의 감정 분석과 자연어 생성을 통합하고, 안면 인식 기반의 자동 팬-틸트 트래킹 제어 알고리즘을 구현했습니다.
* **서버 개발 및 최적화**: 고동시성 모듈형 서버 아키텍처를 구축하여 실시간 센서 데이터(온도·습도) 처리·다중 사용자 세션 컨텍스트 관리·지능형 금칙어 필터링 메커니즘 통합을 담당했습니다.
* **다국어 인터랙션 개발**: 실시간 다국어 전환 및 번역 모듈을 독립 개발하고 클라우드 인지 서비스와 깊이 통합하여, 디바이스가 영어·간체 중국어·번체 중국어를 원활하게 인식하고 상호 번역할 수 있도록 했습니다.

## 프로젝트 상세

*Smart Pot Joi*는 최첨단 AI 기술을 결합한 지능형 식물 케어 및 감성 컴패니언 시스템입니다. 음성 인터랙션·자연어 처리·감정 인식 기술을 통해 사용자의 감정 상태에 맞는 따뜻한 대화와 표정 피드백을 제공하는 동시에, 환경 온도와 습도를 실시간으로 모니터링하여 물 주기를 지능적으로 알려줍니다.

### 개념 프로토타입에서 제품으로의 진화

프로젝트 초기 단계에서는 마이크로컨트롤러 기반의 1세대 프로토타입을 개발했습니다. 이 프로토타입은 주로 핵심 비즈니스 로직을 검증하는 것이었습니다. 온습도 센서를 통한 실시간 환경 데이터 모니터링·사용자의 음성 명령을 텍스트로 변환하여 클라우드에 전송하고 대규모 언어 모델에서 짧고 따뜻한 답변과 해당 감정 상태(미소·놀람 등)를 받는 것·화분 스크린에서 해당 감정 동영상을 재생하는 것 등이 포함됩니다. 이 단계에서 식물 케어와 감성 동반자를 결합하는 것의 기술적 실현 가능성을 검증했습니다.

프로젝트가 심화되고 상업적 잠재력이 드러남에 따라 하드웨어와 소프트웨어의 전면적인 업그레이드를 단행하여 V1 버전을 출시했습니다. 이 버전에서는 기본적인 인터랙션에 그치지 않고 더 자연스럽고 생동감 있는 지능형 컴패니언 단말기를 구축하고자 했습니다.

### 안면 추적과 다국어 실시간 인터랙션

최신 세대(V1) 제품에서는 안면 인식과 자동 회전 팬-틸트 시스템을 도입하여 화분이 실시간으로 사용자의 얼굴을 추적하고 "눈이 마주치는" 느낌을 줄 수 있게 되어 디바이스의 생동감과 인터랙션의 자연스러움을 크게 강화했습니다.

또한 시스템은 강력한 다국어 음성 처리와 실시간 번역 기능을 통합했습니다. Microsoft Azure의 인지 서비스를 활용하여 화분이 사용자가 사용하는 언어를 자동 감지하고 영어(en-US)·번체 중국어(zh-HK)·간체 중국어(zh-CN) 사이에서 원활하게 전환할 수 있습니다. 더 중요한 것은 실시간 음성 번역 기능을 개발하여 언어 장벽을 허물고, 화분을 감성 컴패니언 로봇이면서도 다국어 환경에서의 실용적인 소통 도우미로 만들었다는 점입니다.

### 모듈형 고동시성 서버 아키텍처

점점 복잡해지는 디바이스 측 인터랙션을 지원하기 위해 서버 코드를 고확장성의 모듈형 설계로 재구성했습니다. 서버는 이제 다중 디바이스 동시 요청을 효율적이고 안정적으로 처리할 수 있으며, 다중 사용자 대화의 독립적인 컨텍스트 메모리와 기반 하드웨어 데이터의 안전한 검증 및 저장을 완벽히 지원합니다.

서버는 음성 요청을 NLP 모델로 라우팅하고 음성 피드백을 생성할 뿐만 아니라 지능형 금칙어 필터링 메커니즘도 통합하여 대화 내용의 안전성과 컴플라이언스를 확보했습니다. 소프트웨어와 하드웨어의 깊은 융합을 통해 본 프로젝트는 스마트홈의 실용적인 요구를 충족할 뿐만 아니라 UN 지속가능발전목표(SDGs, 건강과 웰빙·지속가능한 도시와 커뮤니티 등)에도 깊이 부합하여 현대 생활에 고도로 기술적인 감성 동반자를 제공합니다.
