## 我的职责

在这个为期两个月的个人全栈开发项目中，我独立完成了从需求分析、系统设计到前后端实现与部署测试的完整开发流程，主要职责包括：

* **系统架构设计与全栈开发**：负责搭建整个设备租借管理系统的前后端架构，前端使用 Vue 3、Vue Router 与 Bootstrap 5 构建响应式界面，后端基于 Node.js、Express.js 和 MongoDB 实现 RESTful API 与数据持久化。
* **权限控制与认证机制实现**：设计并实现了基于 **JWT** 的身份认证与角色权限控制机制，区分管理员与普通用户的操作边界，确保设备管理、用户管理与借用流程的安全性。
* **设备与用户管理模块开发**：实现了设备信息管理、用户信息管理、设备检索、状态跟踪与借用记录维护等核心业务功能，支持管理员对系统资源进行集中化管理。
* **租借流程与日历可视化设计**：开发了设备借用与归还的完整业务流程，并集成日历视图来展示设备租用情况与时间冲突，提升了设备调度的可视化与可管理性。
* **前后端联调与交互优化**：负责前后端接口联调、表单验证、异常状态处理与交互体验优化，确保系统在不同设备上的可用性与操作流畅度。
