## 我的职责

在这个数据科学与机器学习底层算法探索项目中，我独立完成了算法的推导与工程化实现，主要职责包括：

* **算法从零实现**：基于 Python 与 NumPy 科学计算库，从零开始推导并实现了变分贝叶斯高斯混合模型（VB-GMM），完成复杂概率图模型的代码落地。
* **变分推断逻辑构建**：实现了模型核心迭代过程中均值、协方差、狄利克雷分布参数（Alpha）以及精度参数（Beta）的变分更新方程。
* **数值计算优化**：引入基于 Cholesky 分解的精度矩阵计算方法，有效避免了高维矩阵求逆中的奇异值问题，大幅提升了算法的计算效率与数值稳定性。
* **收敛判定与可视化评估**：设计了基于证据下界（ELBO）的自动收敛判定机制，并开发了通过绘制高斯置信椭圆直观对比自研算法与 Scikit-learn 模型拟合性能的评估模块。

## 项目细节

本项目旨在通过手动从零实现变分贝叶斯高斯混合模型（VB-GMM），深入探索无监督学习与变分推断的底层数学原理与工程应用。在技术执行上，系统首先生成包含六个不同分布特征的多元高斯合成数据集，并采用 KMeans 或随机选取策略构建初始的责任矩阵（Responsibility Matrix）。在核心的模型迭代阶段，算法严格遵循贝叶斯推断逻辑，通过当前责任矩阵不断更新各高斯组件的均值、协方差、控制权重的 Alpha 参数以及控制精度的 Beta 参数。为了解决计算过程中的性能瓶颈与矩阵正定性问题，项目巧妙地应用了 Cholesky 分解技术来处理精度矩阵。同时，模型将其收敛条件严格绑定于证据下界（ELBO）的增量变化，一旦变化量低于设定阈值即判定为推断完成。最终，项目不仅实现了高精度的无监督聚类，还通过直观的二维高斯椭圆可视化，将自研算法的拟合结果与 Scikit-learn 标准库中的 `BayesianGaussianMixture` 模型进行了严谨的对比分析，充分验证了自主推断算法的准确性与鲁棒性。
