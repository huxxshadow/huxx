## 游戏简介

《Floodsong》是一款快节奏的第三人称动作冒险游戏：玩家在海啸中冲浪、在废墟间跑酷，并与利维坦巨兽战斗。

## 我的职责

### 相机

* **分层 FOV 与 Dolly Zoom**：把相机 FOV 重构为基础、速度、能力、打击反馈四层叠加；新增按视锥宽度反推臂长的 Dolly Zoom 模块，实现角色大小不变、背景拉伸的速度感。
* **Boost 镜头**：用状态驱动的渐入渐出层同步驱动 FOV 与 Dolly Zoom，镜头随 Boost 状态开合，参数全部数据化、可在 Inspector 调节。

### 漂移

* **漂移移动**：以受限角速度追赶目标朝向生成弧线轨迹；按弯道累积减速与充能，出弯时结算加速奖励。
* **漂移镜头**：过弯时 FOV 渐开、出弯时脉冲式弹开，并将相机偏航约束在角色朝向附近的软扇区内。

### 速度感 Shader

* **SpeedLines**：把原来基于噪声的 Shader Graph 重写为手写 HLSL。屏幕按角度分槽、哈希抽签，生成离散、头短尾长、会淡入淡出的独立线条；抗锯齿用解析式计算，避开角度接缝处的亮环。
* **RadialBlur**：速度驱动的全屏后处理，同一个 pass 两层效果：中心清晰、边缘径向模糊（按深度门控，远景不糊）；以及高速时近景物体沿速度反方向拉出的卡通化拖影，在离散角度带内做径向 UV 拉伸、在拉伸源点判断深度，让尾巴能溢出物体轮廓，并与速度线落在同一批辐条上。
