## 我的职责

在这个为期三个月的独立开发项目中，我独自承担了全栈游戏开发的工作，主要职责包括：

* **游戏架构与系统设计**：利用 Unity 引擎构建了高度模块化的底层架构，自主设计并实现了包含有限状态机（FSM）的角色控制系统与基于节点编辑器的卡牌式战斗系统。
* **关卡与地图交互设计**：设计了具有“银河恶魔城”特色的非线性探索地图，融合了技能解锁驱动的区域访问限制，以及基于物理系统和动态元素的解谜地形。
* **UI/UX 与前端逻辑**：从零设计了具有复古像素风格的用户界面，实现了即时响应的战斗卡牌拖拽交互与连招实时预览功能。
* **AI 与战斗逻辑开发**：通过行为树（Behavior Tree）系统设计了 Boss 敌人的多阶段战斗 AI，实现了动态索敌、条件触发连招与自适应受击反馈。

## 项目细节

《失落领域》是我首次使用 Unity 引擎独立开发的完整中型游戏 Demo。该项目旨在打造一款拥有扎实动作手感与细腻像素画面的 2D 银河恶魔城类游戏。在开发过程中，我深度实践了游戏工程化管理的各个环节，从核心玩法原型的搭建，到复杂美术资产的加工与集成，再到最终战斗系统的打磨，力求全方位模拟商业化独立游戏的开发标准。

### 模块化动作与状态机设计

角色的动作系统是游戏 3C（控制、镜头、角色）设计的核心。为了保证动作组合的流畅性与可扩展性，我基于有限状态机（FSM）构建了角色控制器。该系统被划分为数十个独立的状态节点（如行走、攻击、冲刺、受击硬直等）。

通过严谨的逻辑控制与动画事件回调，状态机能够完美处理动作之间的平滑过渡与打断逻辑。例如，角色可以在空中冲刺时无缝衔接下劈攻击，或者在受击瞬间触发硬直并打断当前技能前摇。为了进一步提升战斗反馈，我还基于原始的美术素材，手动拆解并重绘了多套帧动画，利用着色器（Shader）实现了流畅的剑气特效与击中时的屏幕顿帧效果。

### 战斗 UI 与卡牌组合系统

为了打破传统的线性连招机制，我设计了一套高自由度的“动作编辑器”战斗系统。玩家可以在探索中收集代表不同“基础动作”、“属性增益”和“特效修正”的卡牌，并将其自由装配在攻击槽位中。

为了将这个复杂的系统直观地呈现给玩家，我进行了深度的 UI/UX 设计。正如以下展示的战斗 UI 界面，玩家可以通过直观的拖拽操作来装配卡牌；当卡牌被放入槽位时，界面顶部的“动作预览框”会实时播放该组合下的完整连招动画与伤害数据。这种“所见即所得”的即时反馈设计，极大地降低了玩家的学习成本，并鼓励玩家根据不同的 Boss 弱点，策略性地搭配出如“重击+破甲”或“高频轻击+雷电核心”等专属战斗流派。

### 像素美术修复与场景氛围搭建

在美术风格上，游戏确立了复古而精致的高对比度像素美学。然而，在初期场景搭建时，部分通过 MidJourney 等 AI 工具生成的像素素材存在着明显的边缘噪点、透视崩坏和色块断层等问题。

为了保证视觉上的极致统一并提升工作效率，我专门开发了一款**《AI 像素画修复工具》**对这些原素材进行深度优化。该工具基于 Gradio、Pillow 与 Scikit-learn 构建，集成了像素化、颜色量化、边缘修复与像素块检测等自动化图像处理功能。通过这套自制的工作流，我成功去除了原素材的杂乱噪点，重新规范了场景的暗部色调与高光轮廓，修补了断裂的砖块与植物纹理，使其完美融入整体的像素环境中。此外，结合 Unity 的 2D 光照系统与动态天气粒子系统（如雨滴溅射、水面波动与多层视差滚动背景），我成功营造出了一个深邃且充满沉浸感的失落遗迹世界。以下展示的即为经过自制工具修复后的精美场景：

### Boss AI 行为树设计

在项目的后期，我重点攻坚了首个核心 Boss“哥布林之王”的设计。为了让 Boss 展现出极具压迫感且智能的战斗节奏，我抛弃了简单的硬编码逻辑，转而使用行为树（Behavior Tree）系统来驱动其 AI 决策。

行为树通过不断的条件评估（如玩家距离、自身血量阶段、当前站位）来动态选择最优的动作分支。例如，在第一阶段，Boss 会以试探性的突刺与格挡为主；当血量低于阈值进入狂暴阶段时，行为树会解锁高频连招与大范围环境破坏技能。这种模块化的 AI 架构不仅使得 Boss 的攻击模式难以预测、极具挑战性，也为后续开发更多种类的高难度敌人提供了稳定的代码框架。
