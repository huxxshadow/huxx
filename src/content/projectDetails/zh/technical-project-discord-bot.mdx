## 我的职责

在这个基于 Java 的 Discord 聊天机器人项目中，我主要负责核心功能模块的开发与面向对象设计的落地，主要职责包括：

* **核心功能开发**：独立设计并实现了身份验证机器人与成绩查询机器人，确保其能精准响应用户的特定指令与文本消息。
* **架构设计与落地**：深度运用多态、抽象类和接口等面向对象编程核心概念，参与构建了基于抽象基类的模块化系统架构。
* **指令与消息处理**：负责集成与区分处理逻辑，将斜杠命令的解析交由指令机器人（CommandBot）处理，而将日常交流与简单交互交由文本机器人（TextBot）监听与响应。

---

## 项目细节

本项目是面向对象编程课程的期末实践项目，旨在通过开发功能丰富的 Discord 聊天机器人，全面应用并巩固多态、接口继承以及复杂系统架构设计等核心编程思想。

在技术实现上，项目基于 Java 与底层通讯库（Java Discord API）开发，采用了高度模块化的架构设计。系统中所有的具体功能模块（如负责测试网络延迟、查询考试座位号、管理用户注册、身份验证及成绩核查的机器人）均继承自同一个统一的抽象基类。为了精准处理不同类型的用户交互，系统将交互机制划分为两类：一类是专门解析斜杠命令的指令机器人，另一类则是监听常规文本消息的文本机器人。这种抽象与多态的设计不仅极大提升了代码的复用性与可维护性，也为系统未来扩展更多实用功能奠定了坚实的架构基础。

---

> **核心技术与架构说明**
> * **编程语言与框架**：基于 Java 原生开发，并调用 Java Discord API 进行底层通讯与交互。
> * **面向对象设计**：深度应用了多态、接口与抽象基类等核心开发范式，构建了高内聚、低耦合的模块化机器人系统。
