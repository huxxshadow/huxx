## 我的职责

在这个由四人组成的数据库管理系统团队项目中，我担任了组长、应用开发者与数据库设计师的角色，主要职责包括：

* **数据库架构设计**：主导系统概念设计与逻辑设计，从零开始绘制核心业务的实体关系图（ERD），并将其严谨地转化为规范化的关系型数据表，有效降低数据冗余。
* **后端逻辑与一致性维护**：编写核心 SQL 脚本完成表结构搭建，并开发 PL/SQL 触发器（Triggers）以确保在航班预订与取消等复杂业务场景下的数据一致性与完整性。
* **应用层开发与集成**：使用 Java 与 JDBC API 实现应用层与 Oracle 数据库的底层交互，成功串联起航班检索、座位预订以及动态折扣票价计算等核心功能。

## 项目细节

本项目是香港浸会大学计算机科学系数据库管理系统课程的期末实践项目，旨在设计并实现一个端到端的航班预订系统。在技术路线上，系统后端基于 Oracle 数据库构建，应用层则采用 Java 开发，利用 JDBC 实现双向数据交互。在整个开发生命周期中，团队严格遵循了数据库设计的标准范式：首先明确了航班、客户与订单等核心实体并完成了 ERD 建模；随后进行了主外键定义与数据库规范化处理；最后将底层架构与上层业务逻辑深度绑定。为了保证票务系统的严谨性，我们在数据库内部署了 PL/SQL 触发器来实时同步航班余票状态，并根据中转次数自动计算阶梯折扣。该项目完整涵盖了从需求分析、数据库逻辑设计到最终应用集成的全流程，是对数据库理论与工程实践的综合检验。
