## 我的职责

在这个基于 WebGL 与 Three.js 的分形形变项目中，我主要负责了分形渲染算法设计、形态混合逻辑实现与整体可视化流程开发，主要职责包括：

* **Ray Marching 渲染实现**：基于 Signed Distance Function（SDF）构建光线步进渲染流程，实现对程序化几何与分形结构的实时表面求交与可视化。
* **Mandelbulb 分形建模**：实现三维 Mandelbulb 分形的距离估计函数，通过迭代公式、极坐标变换与导数累积生成具有自相似细节的 3D 分形结构。
* **形态混合系统开发**：设计并实现传统 3D 模型与 Mandelbulb 分形之间的平滑 morphing 方案，在数学层面对不同 SDF 进行混合，生成连续的中间形态。
* **交互与参数控制**：结合 Three.js 搭建交互式 Web 端展示环境，并支持分形迭代、形变强度、平滑度等参数调节，以提升可视化效果与实验性表现。

## 项目细节

本项目旨在探索传统三维模型与数学分形之间的连续形态过渡，并通过 Web 端交互式渲染展示这种几何表达方式的变化过程。在技术实现上，我采用基于 Signed Distance Function 的 Ray Marching 方法作为核心渲染手段，使系统能够直接对程序化定义的复杂几何进行实时求交与着色。项目中的分形部分基于 Mandelbulb 结构实现，其灵感来源于对 3D Mandelbrot 形式的探索：通过在三维球坐标中对点进行幂次旋转与迭代，可以生成具有丰富自相似细节的三维分形外形。为了实现模型与分形之间的平滑过渡，我将程序化模型 SDF 与 Mandelbulb 距离场在数学层面进行混合，并结合 smooth minimum 与线性插值构建连续的 morphing 过程，使中间状态既保留原始模型轮廓，又逐步呈现分形细节。整个项目展示了 WebGL、Three.js 与程序化几何技术在复杂视觉生成和交互式 3D 艺术表达中的应用潜力。
