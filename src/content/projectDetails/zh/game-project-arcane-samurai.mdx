## 游戏简介

《Arcane Samurai》是一款俯视角像素风 2D 动作游戏的 Boss 战 Demo。玩家在白刀与黑刀之间切换，用居合弹反 Boss 的攻击：普通攻击只能用黑刀弹反，蓝色攻击只能用白刀弹反，黑色攻击无法弹反，只能闪避。Boss 出招时会染上对应颜色提示，血量降到阈值后进入二阶段。

## 我的职责

### 战斗系统

* **玩家状态机**：移动、冲刺、白 / 黑两把刀的拔刀与收刀、三段普攻与剑气、居合的蓄力、释放、弹反与失衡，按状态拆分、互相切换。
* **Boss AI**：距离判断、追击、按权重选招、执行、冷却的行动循环；招式全部数据化（ScriptableObject），攻击属性在出招时锁定；二阶段转场演出（跪地、黑屏、重置站位）。
* **判定系统**：攻击判定轨道按动画归一化时间开窗、按帧切换形状、可按八方向单独覆盖，与移动碰撞体分离的受击盒；检测基于分离轴的纯几何计算，不依赖物理引擎。

### 工具链

* **判定调试器**：在 Scene 视图中拖动时间轴、直接编辑 Boss 与玩家的判定和受击盒，编辑模式和运行时都可用。
* **资源管线工具**：八方向动画剪辑生成器、从整层合并大图扫描 alpha 烘焙场景碰撞、一键装配角色与场景。

### 技术美术（URP 2D）

* **昼夜氛围**：唯一时间源向 shader 广播全局变量，全屏 ramp 调色（保亮度模式）配合分层材质染色，支持正午、黄昏、夜晚三个时间点切换。
* **分层 Sprite 光照**：不使用 Light2D，从 sprite 的 alpha 与亮度反推法线做造型光和迎光轮廓光；世界坐标云影、阵风摆动、按颜色识别火焰并逐帧闪烁。
* **场景效果**：跟随动画帧的 sprite 投影阴影（接触硬化）、火把光晕与火星、shader 内程序化生成的落叶（一个 draw call），以及像素对齐的跟随相机和效果总控面板。
