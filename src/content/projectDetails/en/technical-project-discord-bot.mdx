## My Role

In this Java-based Discord chatbot project, I was primarily responsible for developing core functional modules and delivering the object-oriented design. My main responsibilities included:

* **Core Feature Development**: Independently designed and implemented an authentication bot and a grade query bot, ensuring precise response to specific user commands and text messages.
* **Architecture Design and Implementation**: Deeply applied core object-oriented programming concepts including polymorphism, abstract classes, and interfaces, and participated in building a modular system architecture based on an abstract base class.
* **Command and Message Handling**: Responsible for integrating and separating processing logic — routing slash command parsing to the CommandBot, while having the TextBot listen for and respond to everyday conversation and simple interactions.

## Project Details

This project is the final practical project for an Object-Oriented Programming course, aimed at comprehensively applying and consolidating core programming concepts including polymorphism, interface inheritance, and complex system architecture design through developing a feature-rich Discord chatbot.

Technically, the project was developed using Java and a low-level communication library (Java Discord API), adopting a highly modular architecture design. All specific functional modules in the system — such as the bots responsible for testing network latency, querying exam seat numbers, managing user registration, identity verification, and grade checking — inherit from the same unified abstract base class. To precisely handle different types of user interactions, the system divides interaction mechanisms into two categories: one that parses slash commands (CommandBot) and one that listens for regular text messages (TextBot). This abstraction and polymorphism design not only greatly improves code reusability and maintainability, but also lays a solid architectural foundation for the system to expand with more useful features in the future.
