## My Role

In this one-month Android application development project, I independently handled the main feature design and implementation. My specific responsibilities included:

* **Mobile Architecture Design and Application Development**: Developed the entire application in Kotlin using **MVVM** architecture for page logic, state management, and data flow organization, ensuring a clean and maintainable code structure.
* **UI Design and Interaction Implementation**: Built a modern mobile interface using **Jetpack Compose**, implementing core screens including device browsing, search, booking, login, and registration, with interaction flows optimized for mobile usage patterns.
* **Backend API Integration and Data Management**: Integrated with backend device management APIs, implementing user authentication, device query, location filtering, booking submission, and other features, with a repository layer providing unified encapsulation of network requests and data processing logic.
* **Booking Flow and Error Handling**: Implemented the complete business flow for device booking, including date range selection, conflict handling, input validation, and network error feedback to improve application stability and usability.
* **Mobile Experience Optimization**: Implemented paginated scroll loading for the device list, and optimized interface feedback, error prompts, and state transitions to make the application smoother and more intuitive in real-world use.
