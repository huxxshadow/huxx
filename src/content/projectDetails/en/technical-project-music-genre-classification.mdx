## My Role

In this three-person machine learning team project, I served as team leader and data scientist. My main responsibilities included:

* **Audio Feature Engineering**: Used signal processing libraries to preprocess large volumes of audio data, extracting core features from the time domain, frequency domain, and mixed time-frequency domain, and converting Mel Spectrograms into key inputs for machine learning models.
* **Data Visualization and Analysis**: Conducted in-depth visualization analysis of data distributions and acoustic characteristics across different music genres, providing intuitive data support for subsequent feature selection and model construction.
* **Model Construction and Evaluation**: Applied and compared multiple classic machine learning algorithms (such as Decision Tree, K-Nearest Neighbors, Random Forest, etc.) to achieve efficient classification of complex audio features.
* **Hyperparameter Optimization**: Introduced automated hyperparameter optimization frameworks (such as Optuna) to systematically tune key parameters of machine learning models, significantly improving the final classifier's accuracy and generalization performance.

## Project Details

This project aimed to develop an intelligent system capable of automatically recognizing music genres using signal processing techniques and machine learning algorithms. In the era of highly prevalent digital music, major streaming platforms have enormous demand for automated music classification and retrieval, and this project is a practical exploration of core tasks in the Music Information Retrieval (MIR) field.

Technically, we used an open-source dataset containing 4,500 audio clips spanning 10 different music genres. The early-stage core of the project was audio signal feature extraction: we not only extracted conventional time-domain and frequency-domain features, but specifically converted audio into Mel Spectrograms as the primary data dimension for capturing the essential characteristics of music. During the model training phase, we built and compared multiple classic machine learning classifiers including Decision Tree, K-Nearest Neighbors (KNN), and Random Forest.

To further unlock model performance potential, we applied automated hyperparameter optimization libraries to conduct detailed tuning on each algorithm. Finally, after rigorous evaluation on the test set, our optimized machine learning models successfully achieved high-accuracy classification of ten complex music genres, validating the effectiveness of combining signal processing features with traditional machine learning models for audio classification tasks.
