## My Role

In this four-person database management system team project, I served as team leader, application developer, and database designer. My main responsibilities included:

* **Database Architecture Design**: Led the system's conceptual and logical design, drawing the Entity-Relationship Diagram (ERD) for core business processes from scratch and rigorously converting it into normalized relational database tables to effectively reduce data redundancy.
* **Backend Logic and Data Consistency**: Wrote core SQL scripts to build the table structure, and developed PL/SQL Triggers to ensure data consistency and integrity in complex business scenarios such as flight booking and cancellation.
* **Application Layer Development and Integration**: Implemented low-level interaction between the application layer and the Oracle database using Java and JDBC API, successfully connecting core features including flight search, seat booking, and dynamic discount fare calculation.

---

## Project Details

This project is the final practical project for the Database Management Systems course at Hong Kong Baptist University's Department of Computer Science, aimed at designing and implementing an end-to-end flight booking system. Technically, the system backend is built on Oracle Database, with the application layer developed in Java using JDBC for bidirectional data interaction. Throughout the development lifecycle, the team strictly followed standard database design paradigms: first identifying core entities such as flights, customers, and orders and completing ERD modeling; then defining primary/foreign keys and normalizing the database; and finally deeply binding the underlying architecture to the upper-layer business logic. To ensure the rigor of the ticketing system, we deployed PL/SQL triggers inside the database to synchronize remaining flight seat status in real time and automatically calculate tiered discounts based on the number of connections. This project comprehensively covered the full pipeline from requirements analysis and database logical design to final application integration, serving as a combined test of database theory and engineering practice.
