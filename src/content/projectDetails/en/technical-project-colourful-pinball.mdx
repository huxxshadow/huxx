## My Role

In this two-month solo project **Colourful Pinball**, my main responsibilities included:

* **Game Mechanics and Interaction Design**: Designed the overall gameplay and interface flow, including start menu, settings, in-game, and end screens.
* **Physics System Implementation**: Implemented pinball movement, collision feedback, and gravity effects using **Box2D**.
* **Visual Presentation**: Completed game visual style, particle effects, and collision feedback design.
* **Music Visualization Adaptation**: Based on reference examples, adjusted and integrated music visualization effects into the project.
* **Interface Optimization**: Refined UI layout, volume adjustment, and screen transition features to improve the overall experience.

---

## Project Details

This project aimed to develop a casual game **Colourful Pinball** combining **pinball gameplay, physics interaction, and music visualization**. Based on classic pinball mechanics and paired with vibrant visual style and dynamic audio-visual feedback, the game provides players with a relaxed and entertaining interactive experience.

During development, I used the **Box2D** physics engine to build the core movement system, making the pinball's bouncing, collision, and force responses more closely resemble realistic physical behavior. At the same time, I designed a complete game interface structure — including main menu, settings screen, in-game screen, and end screen — allowing players to experience the game content within a fairly complete flow.

To enhance the project's expressiveness, I further added **music visualization**: in specific scenes, the background and particle effects dynamically change in response to the rhythm and frequency of the music, giving the game not only basic playability but also a degree of artistic presentation. Ultimately, as an early work from my first year, this project not only helped me systematically practice the combination of game development, interface design, and visual presentation, but also gave me initial experience in fusing technical implementation with creative expression.
