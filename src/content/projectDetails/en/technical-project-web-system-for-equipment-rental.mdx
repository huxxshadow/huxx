## My Role

In this two-month solo full-stack development project, I independently completed the full development pipeline from requirements analysis and system design to frontend/backend implementation and deployment testing. My main responsibilities included:

* **System Architecture Design and Full-Stack Development**: Responsible for building the full frontend and backend architecture of the equipment rental management system — the frontend using Vue 3, Vue Router, and Bootstrap 5 to build a responsive interface; the backend implementing RESTful APIs and data persistence using Node.js, Express.js, and MongoDB.
* **Access Control and Authentication Implementation**: Designed and implemented a **JWT**-based identity authentication and role-based access control mechanism, distinguishing the operational boundaries between administrators and regular users to ensure the security of device management, user management, and rental workflows.
* **Device and User Management Module Development**: Implemented core business features including device information management, user information management, device search, status tracking, and rental record maintenance, supporting centralized management of system resources by administrators.
* **Rental Flow and Calendar Visualization Design**: Developed the complete business flow for device borrowing and return, and integrated a calendar view to display device rental status and time conflicts, improving the visibility and manageability of device scheduling.
* **Frontend-Backend Integration and Interaction Optimization**: Responsible for frontend-backend API integration, form validation, error state handling, and interaction experience optimization to ensure system usability and operational smoothness across different devices.
